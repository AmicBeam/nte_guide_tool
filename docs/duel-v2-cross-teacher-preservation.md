# 旧教师行为保持实验

状态：长期设计与实验边界，不表示已经训练成功或可以替换网站模型。现行规则、训练入口和完整评估仍以[训练手册](duel-v2-public-training.md)和[完整报告规范](duel-v2-full-training-report-spec.md)为准。本文件不授权正式长训、发布或改写旧规则哈希。

## 问题

`five-cross-20260924` 的同构筑纯网络对照里，新的 `cross_five_grounded_wdl_v1` 对仓库旧 `fixed_ten_v1` 策略分别为 **0/128、0/128、19/128**。记录见 `artifacts/rl-evals/five-cross-20260924/repo-compare-pure-32/report.md`。这是后续是否恢复旧行为的验收边界，不是服务批准，也不能写成“旧模型可在当前网站直接运行”。

旧文件规则指纹已过期；当前正式加载器会拒绝它们。研究适配只能按**具名观察列和合法动作列**映射到现行 `cross_five_grounded_wdl_v1` 根局面，不得改写旧清单里的 `rule_hash`，不得读取对手暗牌，也不得把旧服务授权带到新学生上。

真红与浊燃在仓库 `app/modules/card_game/engine/ai/models/` 中没有对应旧教师，**不能声称被本实验改进**。

## 范围

只覆盖创生、覆纹、快攻三套。学生是隔离的实验网络，契约为当前交叉编码；教师是仓库只读的 `fixed_ten_v1` 数值文件。数据只用已经归档、完整终局的现行规则训练 episode，按**配对根种子**切成拟合集和原选择集；已经看过的确认种子不得再参与挑选。

学习目标：

- 策略：保留当前 Gumbel 完整策略分布的交叉熵目标；仅在双方都合法且旧教师能表示的动作上，另加学生相对旧教师动作分布的 KL 能力保持项。每次试验在优化前记录系数网格；2026-09-25 有界离线试验使用 `(0, 0.2, 1.0)`。系数为 0 时与原 Gumbel 策略＋终局 WDL 更新逐张量一致，不把只模仿旧教师冒充新提升。
- 如果 KL 锚点的留出评估同时提高具体动作命中却增加攻击／结束回合误出牌，只能另立有界研究对照：以旧教师**具体第一动作**作监督项，仍保留 Gumbel 交叉熵和终局 WDL；系数、数据边界与接受规则在该次优化前冻结。直接模仿旧教师最多是能力恢复，不能冒充超过旧教师的实战胜率。
- 价值：只使用实际终局 WDL，不把搜索 Q、出牌次数或过程奖励写成胜负。
- 不支持的动作（浊燃座位、浊燃牌、旧教师没有的候选列）直接拒绝，不伪造旧列。

## 报告口径

三套各自单独报告，分母写清：

- 精确动作一致、同一张牌一致
- 有合法出牌根上的出牌 top-1
- 攻击被改判成出牌、结束回合被改判成出牌
- 交叉熵、拒绝动作数、重叠合法根数
- 永远出牌 / 从不出牌等坍缩

对照对象仍是上述 0/128、0/128、19/128。纯网络不再出牌、或相对该边界明显更差，按训练手册的 P0 处理，不能解释成本实验已经成功。

- 模块：`app/modules/card_game/rl/cross_teacher_distillation.py`
- 检查：`scripts/check_duel_v2_cross_teacher.py` 默认只做 dry-run 输入校验，不训练、不写产物、不改服务文件

本实验不接入正式训练器、不改规则、不改网站模型、不提交历史报告、不部署。单轮数值只进入 `artifacts/rl-evals/<run-id>/`。
