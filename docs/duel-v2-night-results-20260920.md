## 失败原因与证据

错误：`ValueError: Root pending-choice belief sampling is not implemented for this pilot`。冻结调用链为`search_game → search → sample_world`；该采样器只支持普通行动及起手调度，遇到待选择根局面主动拒绝，没有静默读取真实暗牌。进程退出码1。

第五轮按既定计划首次引入变化配牌，可能暴露此前固定配牌短跑未触达的检视／选择分支；这一关联有计划与轮次证据，但错误根局面、具体卡牌及哪个工作任务未保存，不能锁定具体卡牌归因。第五轮提交12个工作任务，整批结果未归档；不能将这些任务都称为完成、失败或平局，全部排除出统计。

新版预检27项及24局CUDA全阶段短跑、138局冻结流程评估此前确已完成；短跑没有覆盖正式第5轮变化配牌，因此短跑通过不足以保证所有候选牌的搜索根局面均可执行。短跑结果不作为本轮正式模型的强度结果。

修复重点：在保留可见信息边界的前提下支持待选择根局面的信念采样，并为变化配牌中的检视/弃牌/选择分支增加真实搜索回归；为工作任务失败保存种子、配牌与可安全复现的局面。当前仅报告问题，未改变冻结训练代码或恢复训练。
