# 合轴收益表

第四个独立工具模块，入口 `/overlap`，按用户要求仅通过直达链接访问，不在工具主页提供入口卡片。首版支持安魂曲远程、残虹现实/幻境、黑羽魔女形态与明音凛；主要统计普攻、重击，黑羽额外统计魔E衔接，安魂曲额外统计普通E衔接。角色按用户指定时间顺序展示：安魂曲、残虹、黑羽、明音凛，不按属性排序。

网页读取已生成的静态 JSON，只做角色选择、筛选、排序与展开，默认按“倍率 / 占轴最高”从高到低排序。“首个动作”“收尾动作”通过下拉框精确筛选路线中实际的第一个/最后一个动作，选项只从当前角色已生成的合法路线提取；选择首个动作后，收尾选项联动为该起手可到达的合法收尾，切换角色时更新选项并清除不再合法的选择。“是否回场”可查看全部、回场或不回场，与路线类型、闪替代和排序组合，不再提供自由文本动作搜索。展开明细显示在对应操作行下方的独立跨列行，覆盖整张收益表宽度，不改变第一列宽度；可分别展开、收起多条路线，支持键盘操作。路线使用紧凑动作气泡，前台起手实线、后台释放虚线；只在切走前负责预输入下一段的动作气泡上标“预”，正常前后台连段不重复标注。末段本身主动正常切人或脱手切人时，末气泡使用原名加“切”（如魔a5切）；预输入后在后台完成的尾段不加“切”。闪以 `魔a3闪` 等原动作名加闪表示。前后台标记由离线生成的前排区间投影，网页不计算规则。页面不提供“统计口径”卡片，也不在展开明细中展示维护来源列表；计算口径与来源保留在本文和静态数据中。没有计算 API、方案写库、训练依赖；网页请求和网站启动均不运行生成脚本。

## 目录与生成

- `data/rules.json`：角色范围、动作白名单、衔接图、预输入例外与来源。
- `generator.py`：离线枚举、时间安排与裸收益加总。
- `static/data/tables.json`：随网站发布的静态结果，附输入 SHA-256。
- `templates/overlap/index.html`、`static/js/overlap.js`、`static/css/overlap.css`：独立展示页面。
- 动作衔接卡片从静态合法衔接关系和已生成路线列出具体前置动作；多个来源及合法的闪替代来源全部列出，不使用“前段”等泛称，不在网页推测新衔接。
- `scripts/generate_overlap_tables.py`：生成入口，不导入 Flask 应用、不初始化数据库。

只读取排轴的 `actions.json` / `characters.json` 数据文件，不依赖排轴领域服务；不修改排轴动作或权限。更新动作数值或合轴配置后显式运行：

```bash
python3 scripts/generate_overlap_tables.py
python3 -m unittest tests.test_overlap_tables tests.test_module_routes -v
node --check app/modules/overlap/static/js/overlap.js
```

`--rules PATH --output PATH` 可生成临时版本。输入缺时长时输出 `null`，不把占位0秒算作真实免费动作；不认识的角色、动作、没有来源的衔接或超出枚举边界均报错。生成文件必须一起提交，不能在请求时自动重算。

## 现行合轴口径

由用户2026-10-12最新确认：普攻默认顺序衔接；预输入合轴在前一个动作开始0.3秒后输入下一动作并切人，当前动作与已输入的下一动作在后台完整释放，覆盖此前0.2秒预输入口径。操作名使用 `a3预a4`，起手段在完整路线中展示；输入时刻与实际释放时刻分开记录。明音不支持 `a3预a4` 合轴，只保留完整顺接。

正常切人作为独立候选：动作开始0.2秒后结束前排占轴，当前动作完整伤害与资源继续在后台结算，不按打断缩减收益、不额外自动放出下一段。`normal_switch_actions`列举可用动作，`normal_switch_seconds`固定该节点。用户2026-10-12最新更正：安魂曲远程普攻支持预输入合轴，因此a1–a4同时枚举0.2秒正常切人和0.3秒预输入下一段切人；不生成a4孤立起手候选，a5保留完整连段基准。正常切人也可作为多轮合轴的收尾，例如明音a2预a3后回场a4正常切人。

末段没有当前上下文下的合法衔接，或其合法衔接包含本路线首个动作时，额外生成末段不切走的“xx打满”候选，并支持回场后的打满收尾。打满按完整释放时间计算前台耗时，完整收益保持一致，末气泡不加任何后缀；技能、重击与闪等中间分支仍在标题保留。资格仅按已记录的衔接图判断，不因枚举使用次数耗尽而伪装成没有后续，用户2026-10-12确认普攻末段默认完整释放后可接回本形态a1，以 `basic_chain_restart_source` 记录来源并按同形态连续普攻自动补边；该衔接不增加预输入点，不实际执行下一轮。原完整连招基准仍保留；“末段打满（不切走）”可单独筛选这些候选。

用户本轮进一步确认：所有z重击（含幻z、魔z1/魔z2）不能被预输入，必须前一个动作完整释放结束后才直接输入z。`preinput_forbidden_actions`按动作记录禁止预输入的来源，并覆盖所有指向该动作的衔接；不生成a1预z等候选。z释放后能否预输入后续普攻仍按对应衔接配置执行。

路线只从 `start_actions` 配置的合法起手枚举，后段动作仅在衔接目录展示，不生成孤立起手或孤立脱手方案。起手通常为a1/E/Q；当前动作范围内安魂曲为a1远/普通E、残虹为a1/幻a1、明音为a1、黑羽为魔a1/已激活的魔E，不额外扩展既定动作范围。

安魂曲普攻仅远程、不支持闪避保留连段；其他三人的所列形态均支持。只尝试把超过0.7秒的中间普攻替换为0.7秒的闪，首末段不替换；跳过动作的倍率、环合、回能和个人资源全为0。只有前台实线动作可加闪，最终投影落在后台虚线的闪候选会排除。闪不能被预输入，也不能在闪中预输入下一段；必须前段打完再闪、闪完整0.7秒后再输入下一段，替换自动衔接动作时闪仍为手动输入。不用排轴通用0.5秒闪覆盖这个模块的用户指定0.7秒规则。魔a5之后要接魔E的路线必须实际打出魔a5，不能以闪跳过激活前置。

衔接动作合轴：在预输入尾段结束时切回来继续下一段。窗口1为首次切走到尾段释放结束；窗口不足1.2秒不生成。允许回场范围为 `[首次切走+1.2秒, 尾段结束]`，结果选尾段结束时回场，累计两段前台时间。窗口只描述可供其他角色使用的时间，不编造队友操作与收益，也不添加未知的连段宽限期。

多轮路线标题保留两次切人的简称，同时列出回场后到最终切人前的完整中间衔接，含技能、重击、闪替代与脱手；第一次切人前若含这些特殊分支，也列出相应前缀。标题从实际动作列表生成，不按角色硬编码，避免含魔E回接的长路线与普通两段路线共用一个省略关键动作的标题。

“前台合计 / 动作结束”合并为一列两行：第一行突出累计前台耗时，第二行以灰色字显示整条路线的动作结束时刻；“合轴窗口时长”按实际时序罗列每次前台耗时和回场后台窗口，每行一个纯时长气泡，前台实线、后台虚线。离线生成 `foreground_segments`，分别记录每次上前台的起止时刻与耗时。`overlap_windows`只记录切走到下次回场续连段的后台空档，标明时长、起止时刻及满足1.2秒冷却后的可切回时段；最后一次切走后不回场的后台尾段不生成窗口，也不展示包含该尾段的“脱离前排”总列。时间只在对应列及展开明细展示，操作路线保留动作气泡和切走/回场提示。这些字段由离线脚本生成，网页不做时长或冷却计算。

用户2026-10-12新增安魂曲普通E→a5远，以及a4远脱手→普通E；E可作为起手。普通E的完整0.8秒与脱手0.5秒、a4远脱手0.5秒和动作收益均读取当前actions.json。a4远→E直接衔接，不预输入E；E→a5远沿用默认0.3秒预输入规则，并保留完整顺接基准。E单动作可按其已记录0.5秒脱手切人，a4远的正常切人候选保持原口径。新增衔接来自用户确认，不修改排轴动作配置。

黑羽魔a5接魔E时改用现有脱手版本0.6秒，伤害与资源完整保留。用户2026-10-12进一步确认：魔E不支持预输入，必须前台完整释放后才能输入魔z2；魔a5→魔E也只允许直接顺接，魔E不能作为后台预输入尾段。魔z2自动接魔a3。只有这些显式回接路线允许按 `max_uses` 再走一次魔a3–魔a5，魔E仍最多一次；不是无限连段或技能CD搜索。

衔接配置可写 `input_delay_seconds`（从前动作开始到输入的延迟）、`switch_delay_seconds`（输入后额外等待）、`can_preinput=false`（前动作结束时直接输入，不提前排队）、`detach_previous=true`（前动作必须脱手）、`automatic=true`（自动衔接，无再次手动输入）、`requires_previous` / `requires_prefix`（上下文约束）；动作覆写 `locks_foreground_switch=true` 要求完整释放区间由前台覆盖。`start_actions`与`character_order`分别维护合法起手和展示顺序。这些属性分别记录输入、合轴与释放时刻，避免把延后合轴误算为丢伤害。

## 来源与收益边界

三份腾讯资料于2026-10-12读取：

- [明音凛](https://docs.qq.com/aio/DVWd1dEhxd1ZEU25Y)：闪避保留连段及预输入描述。
- [黑羽](https://docs.qq.com/aio/DVVRZempSSmZ4THVj)：普通z插a1/a2/a3且保持段数；魔a2接魔z1、魔z1接魔z2、魔z2自动接魔a3。
- [残虹](https://docs.qq.com/aio/DVXF0ZkVKSEV3Y2t4)：现实与幻境a1/a2可插重击。用户本轮进一步确认两种插入点均接本形态末段：现实a5、幻境幻a4。

只摘取所需衔接语义，不保存原文全文、鉴权数据或其中的攻略评价。数值继续读取仓库当前维护值；腾讯文档旧数值不回退仓库已确认的新口径。例如明音耗时仍为2026-10-11的0.5/0.5/1.1/0.7秒。残虹/黑羽等经验耗时是试算分母，不宣称为实测帧数。

倍率按攻击/生命/防御/固定基准分别加总；动作回能、固定返还、耗能与净能量分别记录；环合本体与释放奖励分列。`/秒`分母为累计前排占轴，不是完整释放时间。不模拟Buff、配装、资源上限/溢出、队友回能分享、形态激活、恶意追加及DOT后续伤害，不等价于真实DPS。幻境和魔形态路线以该形态已建立为前提；尾段离场与再次回场的连段保留采用用户本次指定的参考表口径，不改变排轴引擎。

验收包含生成结果与输入一致、预输入时间、明音例外、闪收益归零、1.2秒窗口边界、分段占轴、魔E脱手/自动回接，以及真实页面筛选、明细和手机横向滚动。
