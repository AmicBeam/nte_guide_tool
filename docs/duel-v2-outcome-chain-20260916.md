## 本轮发现与修复

1. SSH 会话需先加载已有 `vcvars64.bat`，否则 MSVC 找不到 `stdint.h`。
2. 默认 CUDA 驱动 JIT 档再次长时间等待，终止该次尚未训练的预检；使用已有短测配置 `NTE_CUDA_FAST_COMPILE=max`、`NTE_CUDA_JIT_OPT_LEVEL=0` 通过。该档吞吐不代表默认优化档。
3. smoke 默认 hidden=32 与旧模型 hidden=64 不匹配，新增 `--hidden 64` 覆盖。
4. 第一轮短测在创生适配阶段因固定对手变化而被续训校验拒绝；改为热启动后重新使用独立输出目录验证，失败产物保留。
