# 异象对决卡牌描述术语

牌面、异能展示和图鉴效果文案按本文件书写。规则对错仍以 [四人轮替完整手册](everness-item-chain-card-design.md) 为准；本文件不新增机制，只规定怎么写。

图鉴右上角「?」打开机制词表，按基础规则、战斗与卡牌、环合与状态分类，支持名称与说明搜索。词条使用本文件术语，并与完整手册的现行机制同步；卡牌私有效果仍见各自牌面。

护盾词条须明确：新获得的护盾与剩余护盾相加，先扣护盾再扣生命；完全被护盾吸收不触发小吱的伤害获金谷，也不增加九原 J06 的创生伤害次数。玩家与异能者的护盾在己方回合开始时清除，包括后手的开局护盾；异能者返回备战区或倒地时也会清除护盾。玩家开局护盾不再描述为「保留至耗尽」（2026-09-19 用户确认）。

句式参考影之诗、百闻牌：短句、数字、时机在前、选择即目标。不另造专有名词。瞬发、响应采用百闻牌机制，费用改为行动力。

## 卡类

手牌只有三种类型，没有终结标签：

| 类型 | 牌面怎么写 | 不写什么 |
| --- | --- | --- |
| 战斗 | 只写本次攻击修正和额外效果 | 不写「这是战斗牌」，不写无效果的「某某出击。」 |
| 战术 | 直接写效果 | 不写出击，除非牌面真的出击 |
| 武备 | 写成挂在所属异能者身上的持续效果；点名该异能者，不写「本人」 | 不写变身、姿态、增益、弧盘或终结 |

武备牌记述一组新的攻击和生命数值，装备后刷新该异能者面板。战斗牌卡框可写攻击与护盾。**+0 是占位，不显示。** 非零攻击修正均显示，负数如「早起出勤之咏」的 -2 不能省略；护盾只显示大于 0 的那一项。

代码和接口里的 `form` 仍表示武备。**08 是专属武备。** **07 优先用官方角色 PV 名。** 没有角色 PV 时用官方短片或用户指定名。零因速切定位另有第 6 张武备。

## 只用已有的词

下列词已经在手册里，牌面直接用。不要改成影之诗或百闻牌的叫法，也不要另起别名。异能者私有层数和职责（家族壮大、记录、兑现、临时复制、焚印、噩梦、凝视、同频、枚约）写在对应异能或牌面上，不进入本表。衍生牌用展示标签「不可构筑」，只在卡牌大图中显示，手牌区不标记，也不写进效果正文。

**角色 = 异能者 + 玩家。** 没有「敌方」；对面一律称「对方」。

| 用这个 | 不要写成 |
| --- | --- |
| 异能者 | 式神、随从、从者、角色（仅指上场的人时） |
| 玩家 | 主战者、牌手、主将 |
| 角色 | 只在同时包含异能者和玩家时使用 |
| 对方 | 敌方、对手（牌面） |
| 出击 | 发起战斗、攻击（动作） |
| 攻击 | 力量、战力（攻击是伤害字段） |
| 永久攻击 | 当前攻击、面板攻击；永久攻击只含开局攻击和永久加攻，不含武备刷新和临时加攻 |
| 反击 | 还击、反击伤害以外的叫法 |
| 生命 | 血、生命值、血量 |
| 生命上限 | 血量上限、最大生命值 |
| 护盾 | 护甲、屏障 |
| 护盾值 | 战斗牌框上的护盾基础属性；不是护甲 |
| 瞬发 | 快速、免费、不耗费 |
| 响应 | 相应、反击牌、陷阱 |
| 行动力 | 鬼火、费用点、能量（费用） |
| 能量 | 勾玉、进化点 |
| 异能 | 被动、天赋、基础能力 |
| 终结 | 觉醒、进化、超进化（角色按钮，不是卡类） |
| 倒地 | 气绝、破坏、破碎 |
| 备战区 | 准备区 |
| 战斗区 | 战场格（位置，每方 1 个） |
| 前排 | 当前占据战斗区的角色；无人则没有前排 |
| 返回备战区 | 返回手牌、离场、切下 |
| 环合 / 创生 / 延滞 / 浊燃 / 黯星 / 覆纹 / 浸染 / 盈蓄 / 失谐 | 入场曲、融合、协作、同频 |
| 创生花 | 召唤物、衍生物 |
| 武备 | 弧盘、形态、姿态、增益、装备魔法 |
| 附着 | 挂上、持续标记以外的叫法 |
| 公开 | 展示手牌（机制） |
| 前排优先 | 索敌、锁定、优先前排否则打对手 |
| 穿透 | 贯通 |
| 远程 | 射程、远距离攻击 |
| 追击 | 自造简称 |
| 援护技 | 支援攻击、换人斩 |
| 倾陷 | 冻结、锁定、无法换人 |
| 打出 | 使用（当作时点） |
| 弃牌堆 | 墓地、基地 |

卡名用「」：`「要叫大姐头」`。属性写 `光` `灵` `相` `咒` `暗` `魂`。

角色异能展示两行：第一行 `异能：`，第二行 `终结（5）：` 或 `终结（6）：`，括号内是该异能者的能量上限（光/灵/相 5，暗/魂/咒 6）。不要写「基础被动」或「觉醒后」。

旧盖卡的「宣言」「揭示」「部署」「表侧」「当前战力」不写进新版牌面。不要写「本人」；武备点名所属异能者。战斗牌不写无效果的「某某出击。」。牌面不写「敌方」，写「对方」。

## 战斗区与前排

二者不重复。

- **战斗区**是位置：每方 1 个，至多站 1 名角色。
- **前排**是占着该位置的那名角色。战斗区空着时，没有前排。

写位置用战斗区：`若其在战斗区`、`返回备战区`。写攻击对象用前排：`对对方前排造成 2 点伤害`。空前排时的自动改打玩家，用「前排优先」，不要写成「打战斗区」。

## 前排优先

**前排优先**：自动选择当前对方前排；无人则伤害对方玩家。每段伤害或每击开始时重新选择。

这是出击和多数自动效果伤害的默认选目标规则，不要再写成「优先造成前排，否则造成对手」或「无人则伤害玩家」。

| 情况 | 怎么写 |
| --- | --- |
| 普通出击、战斗牌攻击 | 默认前排优先，牌面不写 |
| 创生花、延滞追加等自动效果 | 写「前排优先」 |
| 手牌「对对方前排造成 X 点伤害」 | 出牌必须有对方前排，不能转打玩家；不要写「前排优先」 |
| 攻击附带的追击 | 锁定该次攻击的原目标；倒地或离开战斗区则跳过，不转打玩家；原目标为玩家时仍可追击 |
| 追击且要转打玩家 | 同时写「追击」和「前排优先」 |
| 穿透 | 同一击先打前排，溢出部分打玩家；不是重新选目标 |

```text
造成 1 点环合伤害。前排优先。
造成 1 点追击伤害。前排优先。
对对方前排造成 2 点伤害。
```

## 生命上限

**减少生命上限**：按 1 点逐步削减目标当前生命上限；每减 1 点，当前生命变为 `当前生命 / 原上限 × 新上限`，四舍五入。生命上限降至 0 则倒地。不消耗护盾，不是「无视护盾」。

例如 5/7 减少 1 点上限后为 4/6；再减 1 点后为 3/5。

攻击写「减少生命上限」时，本次攻击伤害改为按上述规则削减生命上限，不再造成生命或护盾伤害。对手是玩家时，没有生命上限可减，改为对其造成等量伤害。

```text
对对手前排减少 2 点生命上限。
本次攻击伤害 +1。减少生命上限。
```

## 援护技与倾陷

入场触发环合后，若入场者为主动出击，本次出击视为 **援护技**。援护技不会受到反击。响应入场仍作为反击方，不视为援护技；只在己方回合可触发环合，对方回合不能。

援护技命中敌方前排时，目标 **倾陷** 值 +1。满 5 后进入倾陷：不可反击；不可打出该角色所属卡牌；不能普通出击、不会在回合开始自动返回，但可以被换下。持续到施加者下个己方回合结束。

**盈蓄**：创生效果伤害时，若目标已有延滞，己方前排获得 1 点能量。

**失谐**：目标已有浊燃时新获黯星，或已有黯星时新获浊燃，敌方前排倾陷值 +1。

**覆纹**：本回合中，灵、咒属性角色攻击后，额外对同目标造成 2 点伤害。状态附着于战斗区，目标倒地或离开则跳过。

**浸染**：对该战斗区的魂、相属性攻击伤害 +2。只看攻击，不看战术、追击或其他伤害。

## 句式

历史中的触发效果写清原因、来源和实际结果，例如「白藏受到伤害，触发异能：攻击 +1。」或「回合结束，零的「倾世之雨」触发：白藏攻击 +1。」。已有伤害、治疗、抽牌事件可在原记录中说明来源，避免重复记录同一结果；未实际获得的数值不写成已获得。不把内部回调名写给玩家。

数字用阿拉伯数字，单位与手册一致：`1 点`、`1 层`、`1 张`、`+1`。一句一事。用 `。` 收句，相关分句用 `；`。时机在前，需要断开时用 `：`。

**战斗牌**

战斗牌打出即出击，不写「某某出击。」。只写修正和额外效果；没有额外效果时描述可为空。

```text
额外造成 1 点追击伤害。
本次攻击伤害 +1。减少生命上限。
若本次入场触发了环合，本次战斗不受反击。
```

**战术牌**

```text
抽 1 张牌。娜娜莉获得 1 点能量。
对对方前排减少 2 点生命上限。
选择另一名己方存活异能者。回复其 2 点生命。若其在战斗区，再给予 2 点护盾。
```

**武备牌**

卡框写一组新的攻击和生命，例如 `攻击 2` `生命 5`。装备后刷新该异能者面板。描述只写持续效果：

```text
每个己方回合首次完成主动出击后，若娜娜莉存活：回复 1 点生命。
零入场触发环合后：本次出击第一次攻击伤害 +1。
每个己方回合，己方首次结算创生花后：为本次创生的入场者回复 1 点生命。
```

**战斗牌基础属性**

卡框可同时写 `护盾 3` 和 `攻击 +2`。打出时先结算护盾；无条件攻击加成展示在卡框上，条件修正仍写描述。

**瞬发 / 响应 / 穿透 / 可重复使用 / 不消耗行动力**

无条件「瞬发」写在描述开头；响应牌先写效果，末尾写「响应：触发条件」。“可重复使用”“不消耗行动力”同样写在描述开头，并与瞬发、响应、穿透、远程一样加粗。规则字段不能代替正文；可重复使用牌结算后返回手牌，真正零费牌不占瞬发机会。卡框费用数字仍用颜色区分：默认青绿，瞬发金，响应紫，两者兼有橙；不在数字旁再写这两个词。响应还要写清触发时机。

**穿透**出现在异能或牌面时同样加粗。薄荷异能用这个词，不写「转移至对方玩家」：

```text
异能：薄荷战斗造成的溢出伤害穿透至玩家。
```

```text
回满娜娜莉的生命。
响应：己方其他异能者被攻击时，自动使用。
第 6 个己方回合及以后具有瞬发。娜娜莉永久获得攻击 +1、生命 +1。
```

**异能展示**

```text
异能：对局开始时获得 1 张「家族壮大」。娜娜莉击退敌人时，若仍存活且在战斗区，再获得 1 张「家族壮大」。至多获得 3 次。
终结（5）：每次战斗附加 1 点追击伤害，持续 2 个己方回合。
```

条件用 `若`，不用 `如果…则`。可选后半不成立时，那一部分不结算，不必再写「否则无效」。

## 写到哪一层

牌面只写打出后看得见的效果。下列内容留给手册，不塞进描述：

- 费用、能否打出、行动力与普通出击次数（所有手牌均为 1 费，卡框不写费用；规则已经有）
- 武备卡框的攻击/生命、战斗牌卡框的护盾和攻击——无条件基础属性可不在描述里重复
- 战斗牌默认出击——不写「某某出击。」
- 瞬发不耗行动力、响应牌末尾明确自动使用——费用和通用接替规则见手册
- 「对手前排无人时不能打出」——效果已经指向前排时，规则本身拦掉
- 「无人则伤害玩家 / 无人则伤害敌方玩家」——已有「前排优先」
- 「家族壮大已满则不触发」——写「获得家族壮大」即可
- 「该追加不是环合伤害」——已有「追击」
- 武备刷新面板、替换不叠层、倒地卸下——写在武备规则里
- 倾陷满 5、时停不可闪避、生命上限逐步四舍五入——写在对应关键词规则里，牌面只写关键词

例外要写在牌面上：玩家会算错的那种。例如「目标无护盾时仍获得能量」。

检视、展示、选择各只做一次。空牌库、不足张数按手册，牌面不必复述。

## 战斗区状态与倒计时

状态施加在战斗区；延滞等前排状态不影响换下的角色，持续伤害仍可分配给存活的备战异能者。黯星无前排时伤害玩家；浊燃等持续伤害无目标时不转打玩家。右侧显示名称和剩余时间。倒计时在所属方回合开始减 1，先触发开始效果再减少；归零效果与倒地恢复在归零时触发。

浊燃：视为持续伤害。己方回合结束时造成等同于层数的伤害，随机分配给对方存活异能者，持续 2 个己方回合。此处己方指施加方。黯星：计时 2 个对方回合，归零时造成 2 点伤害。延滞：持续 1 个己方回合，首个回合中对方前排攻击 -1；在施加方回合开始递减。通用词表不包含创生强化或延滞强化。

## 2026-09-15 牌面补充

- 「开始净空」：己方回合开始时，薄荷自动出击。此次攻击不会获得环合值和能量。
- 「过往消息皆为利刃」：瞬发。造成 1 点伤害。前排优先。若目标为异能者，附着枚约。若目标原本已有枚约，或目标是玩家，抽 1 张牌。

「原本已有」指本牌伤害前的状态，避免把本次新附着的枚约算入条件。具体结算边界见完整手册。

## 2026-09-16 诓定解放

武备面板为攻击 2、生命 6（用户指定生命增加 1，桌游试玩数值）。牌面保持「回合结束时，获得 1 点行动力。」：指己方回合结束立即回费，供对方回合响应使用；下个己方回合正常刷新。历史应写已获得行动力，不写「下个己方回合额外获得」。

白藏 B08 牌名按用户确认更正为「茶花会」；效果、面板和卡牌 ID 不变。历史报告保留当时名称。


### 2026-09-16 伊洛伊「想做什么梦？」倒地时点调整

牌面：己方其他异能者倒地后，造成 2 点伤害。前排优先。

这是用户指定的桌游规则调整。伊洛伊自身倒地不触发；同一伤害阶段的倒地角色先全部返回备战区、完成倒地清理并卸下武备，再通知存活异能者「己方异能者倒地后」。伊洛伊须存活且仍装备该武备。双方前排同时倒地时，存活的伊洛伊因此造成的伤害按空前排打到对方玩家，不受 A/B 座位顺序影响。仅对方异能者倒地不触发。


### 2026-09-16 白藏终结目标

### 图鉴环合词条格式

环合标题统一为「名称 · 属性 + 属性」。正文按「效果」「持续」「说明」排列；创生无持续状态，用「结算：立即结算」。盈蓄、失谐按「条件」「效果」「说明（如需）」排列，不虚构持续时间。

基础定义可直接用短段落，不强制套用环合的「效果／持续／说明」。多项规则按含义拆分为「发动／次数」「抽牌／上限／空牌库」「触发／限制／战斗」「触发／限制／持续」等；操作提示独立标为「操作」，不得与规则混写。

- 仅指编队成员时使用「异能者」，例如「上一名存活出战异能者」；不使用包含玩家的「角色」代称。数值变化统一写「倾陷值 +1」。
- 起手通常抽 5 张、换至多 3 张；回合开始通常抽 1 张，包括先手首回合。通常抽牌遇空库失败，与检视、定向抽牌和定向检索分开说明。
- 终结次数区分玩家与异能者：玩家通常每个己方回合 1 次；启用白热化后从总第 6 回合起为 2 次；每名异能者同一回合仍最多 1 次，复活、补满能量不刷新。
- 响应的倒地／倾陷限制写「通常」，明确「倒地后」响应是该次倒地的例外。接替交战的响应战斗牌作为反击方；主动出击型响应遵循牌面，不能把所有响应战斗牌都描述成接替反击。
- 入场环合明确只在入场者的己方回合触发。对方回合换人不触发、不消耗来源环合值；空前排的退下时满槽条件仍保留。
- X选一先写选择、费用与非主动打出的默认项，再写电脑拖动分区或手机二次选择等操作方式。具体卡牌仍用 ①②③ 列出选项。
