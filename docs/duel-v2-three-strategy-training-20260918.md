# 三套公开预组联赛训练（2026-09-18）

用户授权：先完成正在运行的两套策略90分钟分支测试，再启动三套合计最多90分钟的新实验；公开快攻预组与小吱、海月，作为第三高级策略。未授权自动发布未验收模型。

## 规则与模型契约

本轮冻结当前主目录的正式 Python 规则，支持创生、覆纹、快攻三个固定角色与当前默认32张配牌。旧六人 CUDA 内核尚无完整小吱／海月实现，不能靠扩充角色常量假装已支持。本轮使用正式引擎结算、六个CPU工作进程生成对局，Torch/CUDA只负责网络更新。网页依旧只做NumPy推理，不启动训练。

`official_public_v5` 有八个角色位置、65种牌面、1147个局面特征、85个候选特征。包含公开金谷、借款、角色本回合终结与主动攻击、光抗性、黯星、己方手牌标注以及二／三选一选项；对手暗牌与牌序不进入模型。关闭演出预览的观察路径与网页完整投影须编码一致。

旧 `resident_public_v4` 仅作为热启动来源：按明确的字段名迁移第一层列，新角色／新牌／新机制特征权重为0；其余网络与价值头复制。快攻从覆纹权重初始化，不称此前已训练快攻。规则哈希、65牌/八席顺序、数值权重SHA、实际配牌SHA均独立绑定，旧模型验证不会继承。

## 学习与算力分配

每批4局普通对局产生一次PPO批次更新（内部包含多个优化步，不等于一步优化）；随后最多3个真实训练根局面，每根比较最多6个候选、每候选8个隐藏样本。候选兼顾高分与低概率探索。终局胜/负为+10/-10、平局0；截断不当平局或负标签。部分分支截断则整个根排除，全部同分则不更新，未采样候选不标为差动作。

敌方未知配牌从公开阵容、弃牌、揭示、总牌数和公开生成计数重新构造，每角色原始8张、同名最多2张；Q05常驻复制和NF01使用公开数量单独约束。不会把真实暗牌多重集用作教师池。己方未知牌序重新打乱；隐藏实体/实例ID及规则随机流重建。每粒子必须与原根的学习方输入完全一致。敌方私有金谷标注重新抽样。

每个候选使用相同粒子和随机种子。一半续打使用冻结模型贪心，一半使用温度1.5的冻结随机策略，缓解弱续打策略把候选一概评成相同败局。分支终局均值经温度4形成学习目标；对阶段开始策略加入0.05 KL约束，限制遗忘已有策略。它们是训练正则，不是伤害等人工过程奖励。分支样本均值与价值头都不冒充校准胜率。

## 选择、验收与截止

- 两轮交替训练，每轮各训练创生、覆纹、快攻720秒。同轮对手固定引用上轮已选模型，六阶段共72分钟，均受全程5400秒硬截止约束。其余时间用于评估、记录与交付；无需为了凑满90分钟空转。
- 阶段开始及每5个循环，在两套冻结对手上做32局先后手配对选择检查。超过当前最佳至少2胜才选择候选；少至少4胜则回退并降低学习率。阶段结束只输出已检查的最佳模型，未评估的末尾更新保留为诊断checkpoint，不自动选用。
- 种子隔离：训练815000000段；选择830000000段；新增战术922000000段（沿用M02/N06夹具固定种子730001）；最终945000000段。选择检查用于调参，不作为最终效果证据。
- 最终基线/新策略分别对两套相同冻结基线对手配对测试；三套最终策略另做交叉。三个最终策略分别挑战八名公开角色的全部70种四人组合，使用独立变化配牌与先后手。
- 战术夹具不进入学习，覆盖小吱付金谷斩杀、海月越过前排斩杀、娜娜莉创生保护零并获得家族牌、复活与先加攻后攻击。报告列动作概率，不能把动作概率叫胜率。
- 启动器有独立监督进程，到绝对截止时结束本次工作进程树；失败、截止或未完成评估都不得表述为通过。无新建定时任务，无自动续训，无自动部署。
