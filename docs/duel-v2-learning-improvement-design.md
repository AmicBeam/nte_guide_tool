# 搜索自博弈的学习改进方案

设计日期：2026-09-22。状态：供后续分阶段实现和对照验证的设计，不表示算法已实现或胜率已改善。当前执行顺序、预算、截止及交付仍以[训练手册](duel-v2-public-training.md)为准；本设计不修改已经冻结的运行任务，不授权新训练、延期或发布。单轮实验和数据只进入 `artifacts/rl-evals/<run-id>/`。

## 目标与取舍

目标是让策略从真实胜负中积累、复盘并推广有效打法，逐步摆脱按角色追加手写奖励。保留正式 Python 规则引擎、逐决策信息集搜索、策略／价值联合训练和独立验收；先改善每份经验和每次搜索的利用率，再考虑扩大网络或模拟次数。

当前共享链路的改进切入点是：搜索标签可能延续过尖的策略先验；单次扩展就用价值头截断，未必看见后续配合；真红的过程回报与终局结果共用价值输出；回放以决策行截取和抽样，未按完整对局管理稀有经验。它们是代码层面的风险，不能仅凭一个录像认定某项是低胜率的唯一原因。

保留用户边界：角色与顺序固定，配牌变化另按接受协议；真红免伤期间只分析无收益送队友，不检查空前排、不要求真红留前排、不追加空门惩罚。角色牺牲可能换取胜利，不能统一标为负样本。被用户废弃的训练来源继续禁用。

## 第一阶段：纯胜负价值与可追溯经验

### 1. 分离“能赢”与“触发了机制”

新增独立 `WDL` 头，预测胜／平／负三类，标签仅来自正常终局。搜索主价值使用 `P(win) − P(loss)`，不把 `(value+1)/2` 当成胜率，尤其不能忽略平局。保留辅助机制预测头用于表示学习，辅助标签来自实际事件，不自动转成出牌奖励。

实验初期仍可保留独立的课程回报头，以复现已有短期激励；课程项与 WDL 在搜索中分别记账、显式加权，最终目标实验将前置奖和被动奖同时设为0。只关闭评估奖励不足以证明摆脱人工激励，还需纯胜负训练并重新生成策略标签。

旧标量价值权重不直接冒充 WDL 概率。迁移策略和可兼容主干，初始化新头；先做有界价值预热，再开放它指导搜索。冻结对照也必须具有相同架构、初始化和预热数据，避免把结构迁移差异算成算法收益。

价值查询明确 `viewer`、双方模型／构筑身份和行动方；一次搜索固定价值评估器，不因 `end_turn` 就切到另一套校准尺度不同的模型。只输入该评估视角合法可见的观察。终局符号按玩家身份处理，连续出牌不能按树深奇偶翻转；不同私人信息下的两个预测不强制互为相反数。

联合损失拟定为 `L = w_pi·CE(pi_reanalyse, policy) + w_v·CE(z_WDL, WDL) + w_aux·L_aux`；回放抽样权重作用于对应样本，各项系数、梯度范数和消融单独记录。辅助头即使不加奖励，也可能通过共享主干影响策略，故必须有 `w_aux=0` 对照。初期先旁路训练WDL并验证，再切换搜索主价值；新旧搜索标签按生成版本分区或重分析，不混为同一目标。

记录独立校准集上的 WDL 对数损失、Brier 分数、分桶预测与实际结果，按阵容、先后手和阶段分组。校准集用于调整温度后，另设留出集验证；旧策略轨迹的终局标签表示当时后续打法的结果，不等于新策略继续打的无偏胜率。

### 2. 建立按对局保存的经验池

每个训练 episode 保存规则／编码／构筑／双方模型哈希、种子分区、双方座位、动作序列、学习方观察与候选、原搜索标签、真实终局及奖励版本。私有重放快照与公开录像分开保存。记录轻量恢复信息即可，不强制全量训练遥测进入热路径。

磁盘保留完整对局，内存只维护有界索引和批次；淘汰以整局或合法连续片段为单位。双方决策按对局归组，不能算成两份独立证据。检查点还需保存经验索引、抽样 RNG、优先级、优化器、模型版本和已消费样本计数。

首轮建议抽样配方：50%近期训练经验、25%历史均匀经验、25%优先经验。配方为待验证起点。优先经验综合纯胜负预测误差、策略与复盘标签分歧、样本新鲜度；为稀有胜局保留存储配额和抽样机会，限制单局累计重复使用。胜局不足时回填普通经验，不能将同一局复制为多份新经验。

记录每条样本的真实混合抽样概率 `q(i)`，相对预声明目标分布 `p0(i)` 使用有界重要性权重；报告裁剪及有效样本量。该校正只处理回放抽样偏差，不能消除旧策略分布偏移。纯价值校准使用自然分布留出数据，不能拿胜负强行各半的数据证明概率准确。

SIL 仅作为后续独立消融：低权重模仿优于当前基线的历史决策，设置权重上限和退场规则。第一版优先保留和重新搜索胜局，避免一开始就把整场获胜动作序列硬蒸馏为标准答案。败局仍提供价值监督；其中的好决策通过局面复盘辨别。

## 第二阶段：复盘经验与改进有限预算搜索

### 3. 让模型自己复盘出牌顺序

从训练经验池选取价值误差大、策略分歧大或稀有的状态，用当前冻结模型重新搜索，生成新 `pi`；保留真实 `z` 不变，保存原始／新标签版本与重分析模型哈希。不能把搜索猜测的胜负写成实际胜利。

重分析从该行动方的信息集重新采样未知世界，不能沿用原对局的真实对手暗牌作为已知答案。反事实分支只比较在这些合法采样世界中的结果；若实际继续打到终局，另存新训练分支及其真实结果，不覆盖原局。

先试每批搜索计算量的20%用于重分析、80%产生新局；测量每秒有效标签、独立新局和最终胜率，防止重复复盘挤光新经验。优先用256预算复盘，只有证明更深搜索值得成本后再给少量困难训练根更高预算。

允许少量从训练轨迹合法中盘重置，帮助罕见组合获得后续胜负反馈；第一版上限20%，普通开局仍占多数，中盘成绩单列。起点必须有可恢复的私人观察历史，不能只拼造有利资源。不从用户录像、选择集、校准集或最终验收局面抽取训练起点。

### 4. 比较两条搜索改进分支

- **较小改动：PUCT＋覆盖＋目标修剪。** 保留模型先验，保证低先验分支获得有意义的后续展开。对强制探索产生的访问计数单独记账，实验性地修剪其策略目标贡献，避免网络被迫模仿只是为了探路的动作。修剪规则必须有独立验证，不能随意删除不喜欢的动作。
- **较大改动：Gumbel 候选抽样＋sequential halving。** 在固定总预算内分轮分配、比较、淘汰根候选，并生成匹配该方法的改进策略目标；不能只替换选动作而继续无条件蒸馏旧访问分布。根候选抽样须保留低先验动作机会，记录覆盖率；不宣称256次就穷举了全部行动顺序。

两分支分别与现有256搜索比较。有限预算还要分给不同隐藏世界；增加同一个世界的深度不等于提高信息覆盖。记录根动作访问数、后续分支展开数、独立世界数和各动作估值方差，避免将同一世界反复访问当成独立样本。

增加“跨行动方边界”的价值检查：比较同一方连续两步、回合结束、对手应对后的估值与真实延续结果。可实验按决策步数和完整回合共同限制深度，不允许无界延长。应从数据学到先后次序，不将“Z04→翳出击”写成固定规则。

KataGo 的低／高预算混合可在上述对照之后单独试验：例如大部分决策低预算、少部分深搜索，只将足够质量标签用于策略更新。此为新的实验配置，必须单独标记；不能把低预算对局冒称现行逐决策256完整训练。先做同耗时收益对照，再决定是否修改默认手册。

## 第三阶段：观察表示与对手课程

### 5. 有必要时再升级网络

先审计现有特征能否区分剩余持续时间、效果归属、已用次数、行动力、个人能量和合法后续选择。漏编码先修契约，不能期待更大的网络学出看不到的信息。

随后对照角色／卡牌身份 embedding 与当前数值特征，共享候选打分器，并显式输入自身构筑及公开对手阵容。对手未公开的具体构筑不能因训练调度器知道就进入模型。是否共享多队主干另做消融；按队平衡训练，防止强队淹没真红经验，迁移与导出升级 schema。

若同一当前观察因历史不同而需要不同决策，再加入短事件历史编码（先试小型 GRU）。连续片段含 burn-in，按当前权重重建隐藏状态；不能从独立样本伪造序列。观察以该玩家可知信息为准，曾经合法看过的信息可记忆，未来暗牌不能泄漏。

完整信念网络／ReBeL式公共信念搜索留作后续方向，需要额外建模和验证；本阶段不以名称替代实现。

### 6. 用小型联赛提供可学习的难度

保留当前对手、历史快照、基础规则策略三个来源，先试50%当前冻结快照、30%历史、20%规则的有界配方；各阵容和先后手分层均衡。只在训练池内根据训练胜率调整难度，维持难对手最低覆盖，不用最终验收结果挑对手。

真红几乎打不赢时，增加较早且未废弃的弱快照或规则对手，使它有机会收集不同赢法；随后逐步回到强对手。对弱对手获胜仅是课程数据，不能算强对手验收通过。固定参考对手保留在池外用于阶段选择，不随联赛淘汰。

不用单一总 Elo 掩盖克制循环；阶段看每个对手／先后手，最终仍交付用户要求的新模型互搏二维表。娜白已移除的高级人机不自动重新启用，也不因引用历史研究表自动加入下一轮训练。

## 实验顺序与通过条件

所有比例、模型尺寸、样本数和预算是实施前要冻结的实验配置，不是经过验证的最优参数。第一阶段固定配牌，先把策略学习单独验证，再恢复四轮配牌搜索和等量适应，避免混淆收益。

| 顺序 | 对照问题 | 下一阶段条件 |
| --- | --- | --- |
| A | 新架构共同初始化后，纯WDL与混合回报相比是否更稳定 | 视角／符号／信息边界检查通过；正常终局标签正确；独立价值误差、校准及对局结果可复算 |
| B | 在A基线上，普通回放→分层优先回放→再加重分析，逐项增加 | 真实新经验足够、单局不过量复用；收益出现在新局和新种子，不仅是已见战术题 |
| C | 在选定B配置上，PUCT改进与Gumbel各自对照原搜索 | 同256预算及同墙钟预算分别比较；原低先验分支获得延续，实际胜率支持采用 |
| D | 在选定配置上，身份表示／历史编码／联赛分别消融 | 按队泛化与能力保持有依据，新增复杂度值得计算成本 |
| E | 两种人工奖都为0的新数据巩固＋完整冻结验收 | 自然开局有效、独立胜负改善、完整矩阵和交付通过；课程奖组单列 |

首轮先做A+B的最小闭环，不同时开启全部变量。至少3个独立训练随机种子用于判断方向；训练重复和评估对局不是同一层样本。配对方案按共同评估根种子交换先后手，按对手×先后手等权汇总，报告胜率差及95%区间；聚类以训练重复／根种子为单位，不把同局几十个决策当几十个独立试验。选择时使用预声明有限方案和单独选择集，最终审计只执行一次；证据不足保留基线，不能看结果后追加样本直到显著。

每格128局适合展示矩阵，不足以保证分辨几个百分点的收益。正式预算按预声明最小有意义提升和配对差异方差估算；预算不够则只报告区间和方向，不保证“训练一小时就见效”。同墙钟对照回答单机效率，同新局／优化量对照用于归因，两者分开报告。重分析计算也计入总预算，先预留完整评估与回传，继续服从09:00默认或用户明确时限。

验收分三层：

1. 正确性：真实更新、数值权重变化、恢复一致、暗牌不泄漏、采样分区不串、无非法动作及异常标签。
2. 学习质量：冻结参考对手的独立胜率、纯网络与搜索分别报告；训练触发率、损失和奖励不能代替胜率。前置达成及真红被动仅作机制诊断；免伤队友倒地需结合实际收益解释。
3. 交付：按[完整报告规范](duel-v2-full-training-report-spec.md)完成本轮N×N新模型直接互搏，行先手／列后手／对角线内战，每格胜/完成数；旧陪练附录。实际数值模型、原始证据与公开录像回传并校验；发布另按用户授权。

**数据隔离特别约束：已经看过的评估胜局可以作为问题诊断，不能悄悄进入训练池。若未来明确改作训练资料，必须改变数据身份并永久退出独立验收，重新建立未见种子和局面；本设计默认从新训练对局收集成功经验。**


## 低预算搜索的当前工程入口

末端推荐另提供[根选点离线协议](duel-v2-root-recommendation.md)：先核对Mctx最终最大访问层语义，再分别消融未完成等访问轮次的候选资格与最终先验依赖。实验只改变推理推荐，保留原分配和策略目标；收缩价值推荐不是置信保证或默认训练算法，已见胜线只作诊断，新种子完整对局与退化检查才提供采用依据。

Gumbel根候选分配、内部改进策略分配及completed-Q策略目标已接入共享`information_search`，工程实现和使用约束见[训练手册的低预算章节](duel-v2-public-training.md#低预算gumbel搜索与学习目标)。新十人训练配置默认32次；真红专用对照入口比较16与32次。实现可运行不等于模型强度验收通过；低预算方案仍须用独立对局和同墙钟成本比较，不能用训练集拟合改善、单个战术修正或论文保证替代本项目实际胜率。

正优势自模仿已提供有界消融入口：保留搜索改进策略目标与真实WDL标签，用论文SIL的正优势项强化真实执行且回报高于估值的历史动作；具体系数、数据边界、数值权重续训与验收见训练操作手册。它不按真红机制计数给奖励；实施不等于已通过强度验收。

离线排序辅助项已接到 grounded WDL 的既有策略头：默认系数 0，不改变原优化器；非零时只对超过预声明置信度的完整 Gumbel `pi` 最高合法动作，与其余合法动作中最强 logit 做 softplus 间隔，包括不同牌身份和非出牌类别。它不是出牌加成，截断行不进入该项，价值损失仍只用完整终局 WDL。同数据筛选入口是 `scripts/fit_duel_v2_ranking_auxiliary.py`；原选择集未同时改善动作身份与非出牌保持时，不得写入 CUDA 或正式训练。归档没有未使用的独立确认根，任何通过也只是探索性结果。分解动作头保持断开。

研究实现补充：正常幅度的状态条件残差头、冻结旧策略加零残差初始化，以及CPU容量／留出／精确保留检查已提供独立入口，见[策略学习恢复](duel-v2-policy-recovery.md)。它们不改变上述正式默认值；能记忆教材不等于泛化，保留旧能力不等于新策略更强，完整五套验收仍待独立对局证据。


五套工程入口补充：恢复栈已把策略与终局价值的可训练主干分开，保留具名可表示根的旧策略，并在每批更新后重新核验价值和独立行为；正式放行需真实CUDA32、隔离拟合和容量证据。实现及检验边界见[恢复协议](duel-v2-policy-recovery.md)。这不把本文后续历史编码、重分析与联赛课程全部标为已实现，也不批准模型强度。
