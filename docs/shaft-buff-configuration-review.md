- 装备合法性是所有弧盘 Buff 的前置条件：角色类型必须匹配弧盘类型，非法组合不参与 Buff 与伤害验收。
- `Q` 对应「极轨终结」，`E` 对应「变轨技能」，`援护` 对应「援护技」。
- `action_hit` 按命中后触发，不影响本次命中，只影响后续结算点。
- 敌方 Debuff 统一挂在敌人身上：`延滞`、`黯星` 初始5秒；`浸染`、`覆纹` 持续12秒；`浊燃` 持续15秒。

- 常驻角色 Buff 使用 `trigger.event = passive` 与 `duration.type = permanent`，默认不画在 Buff 线上，但会进入动作详情的生效增益。
- 需要画在时间轴上的永久状态统一使用 `duration.type = time`、`ticks = 9990`、`loop_carry = true`，以999秒 Buff 线表示本轴内永久持续；可视范围只裁剪绘图，不改变状态持续时间。
- 所有 `independent` 独立叠层 Buff 在满层后再次施加时，统一替换当前结束时间最早的一层；“现存 DOT 加层”等间接施加也遵循同一规则。残虹幻a的全队DOT加层按伤害标签识别，每种现存DOT复制为性质相同的新实例，并从触发时重新获得该DOT的完整持续时间和触发间隔，不直接扩写旧实例的层数或剩余时间。

## 当前引擎能力边界

当前 `buffs.json` 支持 `provider.kind == "character"`，以及 `passive`、进入前台、动作开始、命中、结束与环合触发。常驻被动在模拟开始时注册，可按觉醒节点、角色、动作名/类型/标签、前后台、非循环轴、属性、敌方血量和敌方 Debuff 筛选目标；限时 Buff 支持持续、刷新、叠层、触发冷却和切人/指定动作清除。周期回复可按角色最大生命和固定间隔输出回复事件；动态效果可读取目标当前DOT总层数，并按动作末段占聚合倍率的比例把仅作用于末段的效果折算进指定字段。3觉及以上角色的普攻、E、Q、援护有效技能等级按通用规则 +1，但 `被动` 类型伤害不读取技能等级。

当前也支持环合触发事件、依赖其他 Buff 状态触发、共享状态键、按来源角色去重记录、触发时读取并消耗另一状态层数。动作可通过 `cooldown_group` 共用同一冷却槽，自检的冷却读取与动作结算后的冷却写入均使用该共享键；残虹的e、强化e、幻e已按5秒共享CD接入。动态效果可以读取当前负面状态数量、命名 Buff 层数、状态已持续时间和施加者基础属性。全队唯一 Buff 保留各装备者独立触发、独立冷却和独立时间线实例，实际计算时按唯一组只取当前生效数值最高的一份。敌方抗性已拆分为光、灵、咒、暗、魂、相和心灵七类；个人资源会显示在对应角色轨道上。

援护技触发有效属性组合时，即使前一前台角色环合不足100，也会生成对应环合实例，并把该角色现有环合值全部消耗至0。自检警告保留错误级提示，同时明确“当前值”和“距100不足值”；没有前一前台角色、未切换角色或属性组合无效时仍不生成环合。动作打断会按逐段累计配置缩减本次动作的倍率、回能、环合、倾陷和命中段数；选择0段时不派发动作命中及其依赖的 Buff/敌方状态事件，动作开始与结束事件仍保留。援护技、有效耗时为0的前后台动作与真红 `龙e` 不支持打断。

循环轴中的残虹可分别配置0–10层自带蚀心和鸩火，0层表示不携带；两者按既有独立DOT实例、10层上限、30秒持续、1秒共享伤害节拍和50%固定暴击率结算，不占用起始环合单选。配置层先在上一轮轴头参与预热，跨轴尾时继承实际层数、剩余持续时间和下一次伤害tick；若没有同类DOT跨过轴尾，则在本轮0 tick按配置层数重新生成。关闭循环轴时保留输入但不参与结算。

按用户 2026-08-11 补充口径，循环轴自带环合的自检以环合原始实例规则为准，且只检查自带实例所导致的冲突，纯轴内的正常实例冲突不告警。创生最多同时存在3个独立实例，其他环合最多1个实例；所有环合每次触发都生成新实例，达到容量时挤掉开始时间最早的旧实例。自带与轴内实例合计超限时告警。角色机制带来的刷新、延长、加层或频率提升不提高实例上限；残虹可把已有浊燃加至3层并刷新15秒，但不能据此免除“轴内浊燃 + 自带浊燃”的冲突告警。旧浊燃一旦被新实例顶替，其结束 tick 就是不可突破的截止点；即使重叠动作随后补算了更早 tick 的天翼刷新，也不得把旧实例延长到截止点之后。黯星旧实例被挤掉时立即结算其伤害并保留新实例。

动作数据可以产生和消耗按角色槽位隔离的 `personal_resource`；Buff 触发器也可增加个人资源、把指定资源补至角色上限，或按当前有效 Buff 提升指定资源的获取比例。安魂曲「噩梦」已改为敌方独立计时 Buff：最多10层，每层3秒；只要至少存在1层，就沿共享计时每1秒结算一次伤害，叠层不会增加伤害次数或重置计时，但每跳伤害乘结算时仍存活的层数。残虹幻a会为现存噩梦新增1个独立计时层；新增层同时进入周期伤害层数、触发 Buff 投影和由存活实例派生的资源快照，逐层过期后资源快照同步回落。卡厄斯「罪状」上限按1000接入。

当前验收范围固定为单敌伤害轴，不模拟多敌人、击杀或角色受击。随机效果按期望处理。浔 Q 是普通0秒Q，不冻结轴时间、CD或 Buff 时间。追击、协攻、自动援护、创生追加、失谐强化、黯星追加、延滞结算和敌方释放技能触发的伤害等额外攻击由用户手工添加后台动作；只要动作具备来源、觉醒门槛、状态/冷却校验和回归测试，即按完整实装验收。

配装页“当前激活机制”除 `buffs.json` 外，还读取 `mechanisms.json` 中已经进入计算器或手工后台动作的角色天赋。天赋一统一显示为角色的环合强化；天赋二显示当前已接入范围。tooltip 本身即代表机制已经接入，因此不再附加“已实装”“部分实装”等状态文字；若只接入了部分效果，只写实际生效的部分。天赋二已有独立后台动作时按完整实装处理。与天赋对应的 Buff 规则通过 `replaces_rule_ids` 去重。

以下内容不视为完整机制实现：

- `characters.json.modifiers` 中的历史增益；计算内核不再读取这些值。
- `actions.json` 中只有标签、但没有可手工加入的动作、合法性校验和结算规则的追击、附着、DOT、心灵、黯星、延滞等声明；单独的标签不会自动生成追击、协攻、环合或角色状态。已配置并验收的手工后台动作视为完整机制实现。
- `awakenings.json` 中的展示描述；未进入 `buffs.json` 或引擎通用规则就不参与计算。

循环预热统一按上一轮动作顺序重放动作与环合事件，规则的状态修改与 Buff 自身是否结转解耦；轴尾仅保留明确允许结转的 Buff 实例，并恢复配置的初始资源。循环初始环合会继承上一轮修改后的层数、频率乘区等运行时状态，不再在 0 tick 重置为基础层。上一轮在负 tick 自然结束的黯星仍会派发 `reaction_end`，由此生成且允许结转的永久 Buff 必须从本轮轴首进入动作计算，不得只做时间线投影。本轮同类环合触发仍创建新实例；达到实例容量时挤掉开始时间最早的跨轴尾旧实例，黯星旧实例同时立即结算伤害。普通 Buff 继续按各自 `refresh`、`add_stack`、`independent` 规则合并或叠层。
循环初始环合跨过轴尾时还必须继承剩余持续时间与下一次伤害 tick，不得在 0 tick 重新生成完整时长并重置周期相位。0 秒 Q 的冻结区间只负责把计算 tick 映射为显示 tick，不参与环合节拍重置。

## 完成标准

单个 Buff/机制只有同时满足以下条件才可移入文档末尾的已对齐部分：

1. 触发、目标、数值、持续、层数、冷却、清除条件和觉醒门槛均与校对来源一致。
2. 计算详情能区分 `triggered_buffs` 与 `applied_buffs`；资源和手工后台动作能显示来源、条件及前后值。
3. 至少覆盖正常触发、不满足条件、持续边界、叠层上限、切换/指定动作清除五类测试。
4. UI只展示状态，不自行计算角色规则；浏览器结果与同轴引擎结果一致。
5. 删除会造成重复计算的静态增益，并用固定轴回归总伤害、DPS、能量、环合和个人资源。

## 验收关注点

1. 验收数值、持续、层数和触发条件只看校对后规则。
2. 实现状态只用于标记差距，不作为规则正确性的来源。
3. 单层 Buff 的 `max_stacks` 应为1；明确多层的条目按规则配置。
4. `triggered_buffs` 显示当前动作触发的 Buff，`applied_buffs` 显示当前动作实际吃到的 Buff。
5. 非法角色与弧盘组合不作为验收依据。
