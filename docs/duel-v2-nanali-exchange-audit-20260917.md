# 娜娜莉交换价值与复活衔接审查 · 2026-09-17

## 审查结论

按用户确定的定位，娜娜莉不必一直站到下回合；倒地前换取攻击、击倒收益，随后复活并保留成长，是可接受路线。此前将“站不住”直接视为负面过于粗糙。重看同一批32局，第一次交换多数有价值；更需要关注的是中后期交换效率和复活节奏的稳定性，不能据此直接建议加生命或削援护免反击。

## 方法与边界

- 复用交付版创生对快攻32局（11胜21负）的种子与原操作；正式引擎重放后逐局核对胜方、终局回合与事件总数，全部一致。没有新增训练或更改网站规则。
- 一个“倒地周期”从开局存活或一次复活开始，到下次倒地为止。共98个完整周期；另有10个最终存活、未再次倒地的周期不计入每次倒地均值。
- 主动攻击次数按对方实际指向娜娜莉的攻击事件计数，普通出击、战斗牌、自动攻击均单列；反击不当作一次对方主动出击。攻击费用仅计直接相关攻击操作，不包含先前加攻等准备动作。
- 击倒次数按引擎在清理前记录的最后伤害来源归属，包含主动伤害、反击和本人环合伤害；同一对方角色复活后再次倒地会再计一次。观察器只记录，不改变规则。该指标不是对整次击倒的唯一因果贡献。
- “最迟下个己方回合结束前恢复”包含当回合立即复活；能否再次主动出击另计。对局在下一己方回合之前结束的7次倒地，从该复活比例分母排除。
- 伤害吸收指攻击真正扣掉娜娜莉的生命和护盾，不是反事实“若无娜娜莉玩家会少多少血”。数据为固定模型的小样本，不是最优策略证明。

## 一、首次交换多数符合定位

| 首次倒地前／后 | 32局中的情况 |
| --- | --- |
| 承受对方主动攻击 | 25局1次，3局2次，4局0次 |
| 至少承受一次主动攻击 | 28/32，87.5% |
| 直接击倒对方 | 18局1次，2局2次，12局0次 |
| 至少直接击倒一次 | 20/32，62.5% |
| 最迟下个己方回合结束前恢复 | 17/32，53.1%（其中2次当回合立即恢复） |
| 下个己方回合再次主动出击 | 9/32，28.1% |

因此，第一次倒地通常不是无收益送掉。仅有1个首次周期既未承受对方主动攻击、也未直接击倒对方；即使如此也不能忽略她对前排的削血或其他间接效果。

## 二、复活能接上，但并非持续稳定

98次倒地中，91次对局持续到了下个己方回合；其中30次在最迟该回合结束前恢复（33.0%），17次在该回合主动出击（18.7%）。后期这一比例低于首次倒地。

首次倒地后的恢复时点：2次当回合、15次下个己方回合、5次隔两个己方回合、10次等三个己方回合。整批98次中，4次当回合、26次下回合、9次隔两个回合、37次等三个回合，22次至对局结束都未恢复。

实际手动复活使用 Y06 共39次，均用于娜娜莉。当前配牌只有两张 Y06，没有 N06 自复活。下一回合开始仍倒地的87个窗口中，61个当时没有Y06；另有8个下一回合开始时伊洛伊倒地（可与无牌重叠）。这些不能解读成AI主动拒绝复活。

在下一己方回合出现合法Y06复活动作的26个窗口，都完成了复活；本样本没有发现“存在合法复活机会但整回合不救”的普遍问题。

## 三、复活后不立即出击，部分是合理再投资

首次恢复及时、但下个己方回合没有再次主动出击的8局：

- 5局有出击机会，选择打「家族壮大」继续成长，其中4局最终获胜；这不足以证明该选择最优，但不能直接判为浪费节奏。
- 1局有机会让娜娜莉出击，但改由零打出战斗牌。
- 2局复活后行动力已经耗尽。

所以不能把“复活了却没马上出击”全部归因于模型不会用娜娜莉。永久成长、轮换和本回合剩余资源都应纳入判断。

## 四、胜负差异更明显地出现在每次交换的收益

| 指标（按完整倒地周期） | 创生胜局 | 创生败局 |
| --- | ---: | ---: |
| 每周期承受对方主动攻击 | 1.30 | 0.75 |
| 每周期本人直接击倒次数 | 1.59 | 0.72 |
| 周期数 | 37 | 61 |

胜局没有出现“0次对方主动攻击且0次本人击倒”的完整周期，败局有7次；它们也没有直接打掉对方玩家生命，但本统计不把前排削血或队友间接收益折算成得分。胜局和败局长度不同，仍不应把这个关联当成独立因果结论。

对方回合中发生的69次娜娜莉倒地，有29次对方随后在同回合继续主动攻击玩家。第一次此类倒地的24局中，有10局出现后续打脸。因此“挡掉一击”有价值，但未必覆盖对方整轮输出；薄荷穿透和后续攻击仍会造成玩家生命损失。

## 建议

1. 保留以终局胜负为训练目标，不新增“娜娜莉倒地就是坏事”的硬奖励或惩罚。
2. 后续分析优先看每次交换的击倒、吸收攻击、漏伤、及时恢复和返场行动，分别报告，不用倒地率替代这些指标。
3. 若要继续优化，优先对比增加复活密度、保留Y06、复活后的成长／出击顺序及队友承接；需与原配牌同条件比较，不能根据本报告直接断定多带复活牌一定更好。
