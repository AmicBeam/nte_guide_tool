# 搜索纠错小实验：2026-09-19

**结论：搜索结果能被模型学到，部分独立战术题改善，但整体质量门槛仍未通过，不发布权重、不替换默认联赛训练。** 本轮验证的是独立实验路径，不是对线上 AI 的修复验收。

## 实验与边界

用户在“先修搜索、可信比较、样本保持和选模”的方案后授权“试试”。本机 CPU 使用已有 PyTorch 环境，预算最多 600 秒，实际北京时间 01:23:01–01:24:53，约 112 秒，监督退出码 0。未开启自动化或后续长训练，也未向远端传输本轮源码。

每套从与上轮相同的 v4 outcome-only 权重映射开始；快攻从覆纹映射，不继承上轮退化后的权重。使用正式 Python 规则、当前公开八人/三套构筑。无 PPO，仅做搜索标签蒸馏，以隔离“发现好动作后能否学会”这个问题。

实现如下：

- 全部合法根动作先访问，再广度展开两步当前回合动作，最多 512 节点。证明路径可能是当前动作加后续动作；无证明/预算不足均为未知，不当败局。
- 未公开手牌仍匿名化。只在固定已审计规则身份下，对手 AP=0 且公开编队所有可能响应均不可免费发动时，允许继续证明；海月等免费响应可用仍拒绝。未知牌库、真实暗牌/RNG、随机结算和抽牌不参与确定性证明。
- 未证明的动作比较支持全候选 8 粒子初筛，只取一个挑战者，用独立种子 32 粒子与当前首选配对确认；不等幅差、同分、截断或不显著时不生成标签。只有一个实际未证明根运行此流程，合计 192 个分支任务，证据被拒绝；因此本轮学习收益来自证明标签，不能归因于统计复核标签。
- 每套 48 个合成训练局面、24 个选择局面、24 个确认局面、24 个最终留出局面。四组按观察/全合法动作编码指纹去重，种子段分开。保留合法构筑数量与衍生牌边界；这些是合成战术局面，不声称来自自然对局。
- 至多 160 步；未连续选对的训练样本优先复习，混合已掌握样本。两个选模集合都不能下降，且原已会题不遗忘、总正确数提高，才保留检查点。最终留出和旧战术夹具不用于选模。
- 当前蒸馏标签只监督搜索路径的**根动作**；未对所有路径中间状态逐一教学。因此下表是选对获胜路径首步的比例，不代表完整连招执行成功率。这是后续需要补充的检查与训练覆盖。

## 新生成的独立留出局面

每套 24 个未参与训练与选模的局面。目标为最短已证明胜利路径的根动作集合，不把同样短的多个胜利动作强制成相等概率。

| 策略 | 初始选对 | 最终选对 | 原已会题遗忘 |
| --- | ---: | ---: | ---: |
| 创生 | 10/24 | 13/24 | 0 |
| 覆纹 | 12/24 | 17/24 | 1 |
| 快攻 | 8/24 | 15/24 | 1 |
| 总计 | 30/72 | 45/72 | 2 |

训练集：创生 23→31/48、覆纹 18→38/48、快攻 20→32/48。保留检查点分别为第 160、120、80 步。两个选模集合虽无已会题遗忘，最终留出仍有两题遗忘，说明验证集覆盖不足，不能把选模保护当作泛化保证。

总共生成 360 个有证明的根局面，其中 144 个用于训练；训练根中 90 个需要两步。相比前次“确定斩杀根数 0”，此次证明覆盖确实进入了实际训练。

## 原有独立战术与用户录像

以下均在选定最终模型之后检查，没有加入上述训练/选模集合。

- 创生安全创生夹具由失败变为通过，两侧均通过，正确动作集合偏好约 22.89%→68.67%。复活后攻击夹具仍失败，正确动作偏好进一步降低。
- 覆纹先加攻再攻击夹具仍失败，正确动作偏好 38.57%→20.55%。
- 快攻 Q01 强化斩杀仍不是首选；偏好约 0.00038%→15.88%，有提高但未修复。U03 绕过前排斩杀仍为首选，偏好 99.96%→47.96%，尚有遗忘风险。
- 原用户第 3 回合快照：首选从 Z05（82.09%）变为 N02（59.34%）；娜娜莉普通出击仍未学会，不能宣称修好了用户指出的操作。

这些数值是动作 softmax 偏好，不是胜率。

## 小样本整局对照

每套对两个相同冻结基线对手，各 4 个种子交换先后手，即每版本 16 局；两版本三套合计 96 局，全部完成。

| 策略 | 初始胜局 | 最终胜局 |
| --- | ---: | ---: |
| 创生 | 14/16 | 10/16 |
| 覆纹 | 11/16 | 10/16 |
| 快攻 | 1/16 | 2/16 |

样本很小，不能据此推断精确总体胜率，但已经不足以支持上线：创生/覆纹本组胜局下降、两套发生留出题遗忘、三套完整旧战术门槛均未通过。`quality.json` 明确为 `passed=false`。

## 判断与下一步

这轮提供了“更全面搜索得到的动作标签可以改变模型”的证据，而不是整体变强的证据。合成局面主要改变敌方低血量/前排和我方 AP、环合、金谷，缺少我方倒地、复活、防守和长期资源取舍；这种样本偏向与整局退化相符，但尚未通过消融证明因果。

下一步应优先补全证明路径的中间动作监督和整段执行验收，并从自然对局采集可信分支，覆盖复活、防守、资源规划；与原已掌握行为混合后再复核。不会因为本轮局部正确率上升就自动开始长训或覆盖服务模型。
