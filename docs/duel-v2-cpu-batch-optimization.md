# 张量训练 CPU 批量优化（2026-09-14）

## 改动与契约

本次针对 Windows 当前的 CPU 张量规则 + CUDA 网络采样器优化；不修改卡牌规则、奖励、网络结构或训练超参，不声称已经实现 GPU 完整对局。

- `step_index(..., legal_ready=False)`、`advance_to_actor(..., legal_ready=False)` 默认仍重新生成合法动作，兼容外部调用或修改原始状态的使用方式。
- 内部调用在 reset/pack 或 step 已生成合法动作，且中间没有修改状态时，显式传 `legal_ready=True` 复用。每次 `step_index` 返回前仍重建结果状态的合法动作。不增加隐式持久缓存，不允许修改状态后继续声称 legal_ready。
- 移除环境与对手推进中无状态变化的重复重建；对手每次操作复用上一操作输出的动作表。
- CPU 整批没有目标时，跳过卡牌抽取弧盘的牌库/手牌逐槽扫描和空选择流程。
- CPU 整批没有伤害目标时，跳过前排目标枚举与零伤害计算，但保留原来的倒地/胜负结算调用，不因性能优化遗漏全局结算。
- 空mask判断仅在CPU启用，不给CUDA路径增加一次读回CPU的同步。
