## 整理规则

- 基础动作数据源：`app/modules/shaft/static/data/characters.json` 与 `app/modules/shaft/static/data/actions.json`。
- 普攻数值补充源：腾讯文档 `角色技能数值`（sheet\_id `000003`），只补本文已经存在且能稳定匹配的角色/动作，不新增表中额外动作。
- Q 耗能补充源：`异环云配队.xlsx` 的 `角色` 页第 32 列 `大招消耗`；只有动作名为 `q` 的终结本体消耗能量，其余 Q 变种统一按 `耗能：0` 记录。
- 普攻动作名包含 `5a` 的条目，在本文中拆成 `a1`、`a2`、`a3`、`a4`、`a5` 五个拟动作；娜娜莉 `3z` 与 `3z副手` 分别拆成 `z1-z3` 与 `z1副手-z3副手`。
- 已匹配普攻的备注中，“腾讯表”数值按 `倍率呈现方式` 聚合多段 hit，伤害倍率取 `1级倍率`。
- 拆分后的单段时间仍不硬填；若原 `5a` 有总耗时，时间列写“待拆（原合计 xs）”。
- 动作轴轨道按本次口径标注：默认普攻链第 1 段（`a1`）固定前台，普攻链第 2-5 段（`a2-a5`）标为 `前台可后台`；残虹的现实与幻境普攻链均遵循该通用规则。用户另行明确的普攻类动作也可使用同一手动后台能力，目前包括伊洛伊「清明梦」。专用「无」节点同样可在前台与后台轨道间拖拽，后台放置时仍负责切换当前前台角色。每名角色另有通用「闪」动作：固定前台、0.5 秒、无伤害和资源效果，并在动作库中排在「无」之前。显式后台伤害仍按后台伤害记录。后台无时间动作与 `Q/q` 无时间动作的时间列统一写 `0秒`。
- 时间轴动作可双击编辑。脱手是步骤属性，不是独立动作；当前白名单只有安魂曲 `a4远` 与 `e`，两者脱手后均占用 0.5 秒，时间轴名称保持原名并改用脱手专属字体颜色。旧 `a4脱手` 自动迁移为 `a4远` 脱手，旧 `a4闪` 自动迁移为 `a4远` 脱手后接通用「闪」。
- 有效耗时大于0、不是援护技且动作未显式禁用时，才可在同一编辑框开启打断；援护技、前后台0秒动作及真红 `龙e` 不支持打断。打断时长为0.1秒至当前动作形态的完整时长，伤害段数为0至原段数。倍率、回能、环合、倾陷按 `action_hit_profiles.json` 的逐段累计值预览和结算，不按段数比例直接缩放。只有腾讯文档 `角色属性` tab `000003` 中能明确对应的行才标记 `tencent-sheet`；公式中的重复倍率也必须有该表格行背书。缺少逐段原值的自定义动作只以 `aggregate-fallback` 标记后按当前聚合总值均分，不宣称为在线表核实数据。
- 安魂曲表额外记录 `噩梦层数`，该字段与伤害段数分离：`e` 是1段伤害但一次叠5层噩梦，`q` 固定5层；后台动作记0，`前台可后台` 动作切到后台时层数不变。
