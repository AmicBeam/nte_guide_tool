# 双预组训练结束标准与首轮结果

> 本文记录此前约定的训练停止条件，以及 2026-09-15 凌晨 `paired-long-20260915` 的实际结果。训练对象为创生、覆纹快攻的固定预组镜像；不代表后来完整公开卡池训练已经完成。此后首回合抽牌、白热化等规则有变化，历史胜率不能直接作为当前规则下的胜率或平衡证据。

## 1. 何时结束训练

整体训练在以下任一条件先到达时停止参数优化：

1. 从长训开始计时达到 **3 小时**。这是两套模型共享的整体墙钟预算，包含初始化、训练和周期评估，不是每套各训练 3 小时。
2. 到达指定的绝对截止时间。本次为 **北京时间 2026-09-15 09:00**；以后任务必须另设时间，不沿用这个过期日期或自动顺延。
3. **两套模型都满足对规则 AI 的胜率门槛，并且都进入持续无改善的平台期。** 一套先达到平台期可以冻结，另一套继续训练；不能只凭其中一套达标结束全部训练。

时间到达时，即使未达标也必须停止并保存有效模型，结果标记为未达标。异常、非有限 loss/梯度等属于失败停止，不能记作训练达标。

## 2. 胜率门槛

| 项目 | 判定口径 |
| --- | --- |
| 分别验收 | 创生预组、覆纹快攻各自独立判断，不把两者胜率合并 |
| 对手 | 固定版本的 `VisibleEngineRulePolicy`，在正式 Python 规则引擎中评估 |
| 数据 | 评估种子与训练分离；同一种子交换先后手，先后手等量 |
| 周期评估 | 每模型约每 300 秒一次，每次 64 对种子，共 128 局，先后手各 64 局 |
| 门槛 | 所选最佳有效模型的先后手等权总体胜率 **≥50%** |
| 分项胜率 | 分别记录先手、后手胜率，但**不要求二者各自 ≥50%**，允许先后手本身不平衡 |
| 平局 | 单列且不算获胜，仍计入完整对局分母 |
| 完整性 | 截断、异常、样本不足或先后手数量不等的评估不能用于确认达标 |
| 不确定性 | 同时保存 W/L/D、样本数和 Wilson 95% 区间；本次没有额外要求区间下界 ≥50% |

计算式：`总体胜率 = (先手胜率 + 后手胜率) / 2`；先后手样本相等时，等于全部完整对局的胜场数除以局数。训练中批量规则对手的胜负、reward 或自博弈胜率不能替代该独立评估。

## 3. 平台期与 RL 诊断指标

| 参数 | 本次设置 |
| --- | --- |
| `patience` | 连续 6 次有效评估没有显著改善 |
| `min_delta` | 胜率须比上一次显著最佳值**提高超过 0.01**，即超过 1 个百分点，才重置平台期计数 |
| `plateau_seconds` | 距离上一次显著改善至少 1,800 秒（30 分钟） |
| 联合门槛 | 平台期条件与最佳有效模型总体胜率 ≥50% 必须同时满足 |

每次更新记录 reward、loss、value loss、entropy、approximate KL、clip fraction、explained variance、优化器步数、吞吐和显存。它们用于判断训练健康状况和定位问题；本次没有为这些指标约定单独的数值早停阈值，不能仅凭 loss 不下降或熵降低宣告成功。

## 4. 模型保存与结束后的日志

- `latest.pt`：定期及退出时保存，用于恢复训练；包含模型与优化器状态。
- `best.pt`：独立评估胜率改善时保存。最终选择最佳有效模型，不一定选择最后一次更新。
- 训练期间不收集用于卡牌分析的出牌日志，只保留训练标量、评估汇总、checkpoint 和进程状态。
- 优化结束后，每套最佳模型额外执行 128 对种子、共 **256 局**的日志评估（先后手各 128 局），每套最多 600 秒。这一阶段不更新模型，不计入 3 小时优化预算。
- 最终日志记录成功出牌、出牌方、卡牌 ID、对局 ID、种子、先后手、模型版本、事件序号和最终结果。保存原始数据，**不自动分析每张卡的胜率**。
- 后续统计“打出过该卡的对局胜率”时，按 `game_id + 出牌方 + card_id` 去重；同局多次出牌不能算成多局，未完成对局不能伪造胜负。
