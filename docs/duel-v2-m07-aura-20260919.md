# 2026-09-19 薄荷 M07 攻击力光环

用户要求把 M07「对方回合攻击视为 0」简化为攻击力归零光环，并确认：面板归零，响应战斗牌的本次攻击加成仍然生效。

## 实现

- M07 定义 `enemy_turn_attack: 0`，统一攻击力读取在对方回合返回光环值。己方回合、武备被替换或卸下时，按现存永久攻击、武备面板和增益计算，无需存储旧攻击力或回合切换恢复操作。
- 移除薄荷的最终攻击伤害覆写及对应无其他使用者的战斗钩子。战斗仍按面板攻击加本次攻击修正结算；M04「午休时间」在 0 攻面板上提供 2 点反击攻击。
- 正式投影、公开事件局面、预览和属性变化记录使用同一读值，不改写角色的永久攻击与增益字段。
- native/CUDA 共用生成引擎把归零移到攻击力读取；张量引擎原本就在该层处理，与新口径一致。无新增存档字段或网络状态机。
- 卡表和现行手册同步。只调整用户桌游规则，不声称来源于原作或已平衡。
