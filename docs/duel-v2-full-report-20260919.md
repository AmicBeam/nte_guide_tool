## 附录B：统计字段与产物

- `matrix.csv`：每个补评单元的尝试/完成/胜负平/先后手/平均全局回合/异常/截断。
- `selfplay-card-metrics.csv`：镜像主逐卡表，`games`是该位置观测数；seen/drawn/used按局与角色侧去重，`plays`是次数。率由对应局数除以games；条件胜率由wins_when_*除以对应*games。
- `card-metrics.csv`：各类模型对局逐卡表；规则AI不进入主统计。
- `generated-cards.csv`：生成/复制使用单列，不解释无使用样本为规则不支持。
- `mechanisms.csv`：角色×全局回合机会，已用机会取已用键和机会键交集、未用取差集，次数与胜负关联另列。
- `opening-summary.json`：起手保留/换出、首动作与首回合结束前资源；`turn-curves.csv`为仍在进行对局的决策边界局势均值及样本数。
- `training-progress.csv`：周期、预组、先后手及历史/当前对手类型计数；`night-evaluation.csv`保留三版本逐局摘要和复用标记。
- `construction-records.json`：完整构筑、哈希及无调整声明；`config.json`保存任务、种子、对手模型和实际配牌。
- `raw/*.json.gz`：私有动作/卡牌来源/机制/回合/起手；`replays/*.json.gz`：隐藏双方暗牌的公开录像。私有数据不上传公开回放。
