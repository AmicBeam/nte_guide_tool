# 异能对决：环合与角色异能／终结改稿

> 状态：供编辑的设计草案，尚未修改游戏代码。第一节记录已确定的基础调整；「本轮调整」记录本轮改稿，其未明确的边界集中列为待定。其余角色的「建议」仍是未采用候选。本文不视为已经实现或已通过平衡验证。现行规则仍见[完整手册](everness-item-chain-card-design.md)，正式实施时统一更新手册和[牌面用语](duel-v2-card-text.md)。

## 一、已确定的调整

- 每名异能者的环合值上限改为 **3 点**。
- **环合值的基础获取量等于该异能者此次操作实际消耗的玩家行动力；该基础值可以被效果改写。**
- 通常出击也获取环合值，也可以使该角色获得蓝色虚线标记。
- 环合值倒地不消失。现行实现已保留此资源，需要继续保持。
- 最近使用卡牌或通常出击的角色，环合值已满时，在其角色卡外围几 px 处显示蓝色虚线框。
- **环合反应仍需出击触发。** 单纯使用战术、装备武备、增加环合值或亮起蓝框，不自动触发环合反应。
- 移除旧的「前排退下时满槽，留下空战斗区环合机会」机制；包括己方回合开始自动退下和其他返回备战区，不再按退下瞬间存一份环合资格。

### 行动力与通用获值示例

| 操作 | 实际消耗行动力 | 该操作的基础环合值 |
| --- | ---: | ---: |
| 通常出击 | 1 | +1 |
| 使用普通 1 费战术／武备／战斗牌 | 1 | +1 |
| 使用额外消耗 1 点的 1 费牌 | 2 | +2 |
| 瞬发或减费后免费使用 | 0 | +0 |
| 瞬发只免普通费用，仍支付 1 点额外费用 | 1 | +1 |
| 不消耗行动力的牌 | 0 | +0 |
| 反击、无费用追加攻击、直接释放卡效 | 0 | +0 |
| 发动不消耗行动力的终结 | 0 | +0 |

环合值仍封顶为 3。战斗牌的使用与其附带出击属于同一次付费，不能同时按「用牌」和旧「战斗成功 +1」重复增加。角色／卡牌可明确增加、替换或改写这项基础获值；额外获值与基础获值分别处理，均受最终上限约束。

### 创生：即时伤害与持续叠层

**本轮调整正文**

触发【创生】时，保留原有立即造成 1 点伤害的效果，前排优先；同时获得持续 2 回合的【创生】层数。每回合 1 次，当己方异能者出击时，额外造成 1 点伤害，前排优先。【创生】可叠层，上限 3 层；每层独立计算持续时间。叠层仍按每次 1 点逐段结算，不合并成单段等同于层数的伤害。每次追加伤害结算时，均可判定【盈蓄】。

- 普通触发默认施加 1 层；九原将获得层数翻倍，并将上限改为 6 层。
- 新增层数不统一刷新已有各层的持续时间；旧层与新层分别到期。薄荷的溢出刷新属于额外效果。
- 原有即时 1 点不因增加持续层数而删除；即时创生伤害仍沿用【盈蓄】判定，新增追加伤害也具备判定资格。
- 只施加层数不等于再次出击；追加伤害不伪造出击、反击或新的环合支付。

**需补定的结算边界**

| 项目 | 待定内容 |
| --- | --- |
| 每回合 1 次的范围 | 是每层各自每回合 1 次，还是全部层共享 1 次？暂建议每层各 1 次、每段固定 1 点。例如有 3 层时，同次出击依次结算三段 1 点；此例待确认。 |
| 2 回合的计时 | 是否按施加方的 2 个己方回合计算；施加当回合是否计入；回合开始或结束到期。 |
| 当次出击 | 本次出击新触发的创生层是否可在当次出击触发追加；追加位于入场后、攻击前还是攻击后。 |
| 出击范围 | 普通出击、战斗牌、远程、自动／额外出击及同频合击是否分别计入；反击不自动等同于出击。 |
| 满层与刷新 | 满上限时新施加的层数是丢弃、替换最早到期层，还是刷新部分层；普通叠层不自动刷新全部层。 |
| 伤害来源 | 持续层记录施加者还是采用本次出击者；来源倒地后能否继续生效。此项影响娜娜莉参与、真红首次攻击与角色触发归属。 |
| 盈蓄通知 | 每段追加都可检查延滞和回能；真红独行等「盈蓄后」监听按段触发还是同次出击去重，需明确，以防追加伤害循环。 |
| 九原的即时伤害 | 新的「获得层数翻倍」替换旧的创生额外结算；旧即时 1 点是否也保留额外结算：待定。不可擅自把每段伤害翻倍。 |
| 薄荷随机目标 | 建议即时及持续追加均改为随机对方存活角色，每段独立随机；是否包含全部备战异能者按角色范围定稿。 |

## 二、统一边界：请直接编辑定稿

以下是建议口径，未确定项用「待定」标出；不需要一次把所有角色建议都采用。

| 项目 | 建议口径／待定项 |
| --- | --- |
| 获值归属 | 玩家行动力实际由共享池支付，环合值归本次使用卡牌／出击的异能者；按真实使用者，不按被治疗者、目标或原卡作者。 |
| 获值时机 | 建议成功扣费后获得，先于卡框与卡效；普通出击同样先扣费获值。取消／非法操作不扣费、不获值；已经合法支付后攻击被打断，不撤销已获得的资源。 |
| 环合检查顺序 | 建议先锁定此前最近行动的异能者作为候选来源，再处理本次扣费、获值与入场环合；不得在检查前把来源改成本次出击者。环合成功消耗来源的 3 点，不消耗本次出击者的环合值。 |
| 最近行动角色 | 建议每方记录最近一次成功使用卡牌或通常出击的异能者；自己连续行动不会和自己触发环合。其他角色用战术／武备是否立刻覆盖旧来源：**待定，建议覆盖**，让角色顺序直接可读。 |
| 来源更新 | 建议同次战斗牌附带出击只更新一次；普通换位、自动退下、治疗、单纯获值及终结按钮不单独覆盖来源。角色在备战区用牌可以成为来源，无需先站前排。 |
| 蓝色虚线 | 建议 2px 蓝色虚线，距角色外沿 4px；表示「最近行动且环合值已满」，不等同于下一次一定可触发。倒地／倾陷时移除可用提示，不清空个人环合值。不要与已有蓝色实线限伤框混淆。 |
| 零费操作 | 实际消耗为 0 时没有通用获值；但角色原本已满，是否仍可成为最近行动角色并亮框：**待定，建议可以**。 |
| 跨回合 | 是否保留最近行动角色：**待定，建议保留**；保留的是行动顺序记录，与前排退下无关。回合开始不因自动退下新建、转移或恢复来源。 |
| 倒地与恢复 | 倒地保留个人环合值；建议倒地不能提供环合，清除其来源资格。复活不自动恢复旧蓝框，需再次成功用牌／通常出击。倾陷仍不能提供环合。 |
| 反击与自动响应 | 反击不支付行动力，无通用获值、不改最近行动者。响应自动使用按实际消耗获值；对方回合仍不触发己方入场环合。对方回合响应是否覆盖来源：**待定**。 |
| 远程与自动出击 | 必须区分实际出击与追加伤害。远程能否触发环合：**待定，暂建议保留现行不触发**。自动出击无真实扣费则没有通用获值；是否覆盖来源另需定稿，不能默认为通常出击。 |
| 特殊卡效 | 独立卡效直接施加创生／覆纹，及既有不消耗环合值的例外如何保留：**待定**。本次「需出击触发」是否连这些例外也取消，需要逐牌处理。 |
| 效果改写获值 | 已确定：行动力等量仅为基础值，可以被效果改写；明确的额外获值可独立增加。多种增加／替换效果同时存在时的顺序仍需定稿。 |
| 回费与退费 | 建议行动力返还不倒扣已获得的环合值；真实取消支付则撤销对应获值。不能将「原价 1、实际免费」算作消耗过 1 点。 |
| 白热化 | 旧第 13 回合上限降为 1 与新上限 3 冲突；建议删除此项环合降上限，能量上限调整和其他阶段规则另按现行保留。**待定是否全程固定 3 点。** |
| 能量 | 本次仅改变环合值。建议保留原战斗能量规则；不要把行动力消耗同时换成能量，也不要把环合值当作终结能量。 |

### 本轮角色待补项

- 娜娜莉「参与触发」是否包括提供环合值者和发动者；持续层的出击追加不自动等同于重新触发一次创生环合。终结「已有创生／覆纹」需明确所属方与检查时点。
- 九原终结的全体基础伤害数值、替换／额外关系、可选结算方式；旧创生即时重复与附枚约是否保留。
- 伊洛伊的延后施加是否每次触发均排程、是否仍不可叠加，以及不占上限层是否仍可被九原翻倍。终结发动当回合无新的回合开始，需明确两个回合开始的覆盖范围。
- 白藏的 xx／xxx 触发条件与完整终结正文。
- 小吱追加金谷的数量、盈蓄回能受益者范围与满能量边界。
- 薄荷刷新哪些独立层及每层刷新到何时；九原对全体造成伤害时与随机创生的优先关系。
- 真红独行改为伤害后是否仍进入战斗区；首次攻击的定义及这段伤害的分类。

### 顺序示例（按上述建议口径）

1. 零原有 2 点环合，使用实际消耗 1 点行动力的战术牌：零变为 3 点，成为最近行动角色，显示蓝色虚线；此时不触发环合。
2. 娜娜莉通常出击：锁定零为来源，自己按实际消耗 1 点行动力获得 1 点环合；满足存活、状态与光＋灵组合时，消耗零的 3 点并发动创生，娜娜莉本次出击为援护技。不能先把来源改成娜娜莉而丢失零。
3. 若零改为通常出击后达到 3 点，同样显示蓝色虚线，下一名角色出击仍可接环合。
4. 零满槽后，娜娜莉只使用战术：不会因此触发创生；若采用「任何用牌均覆盖来源」，接下来检查的是娜娜莉，零不再显示来源框。
5. 某角色本来有 3 点，倒地后仍保留 3 点；这不代表倒地期间能提供环合，也不代表复活后恢复原来源顺序。

## 三、角色改稿约定

- 共列出当前 21 名角色，公开 17 名与测试 4 名分开；不改变账号可见范围。
- 「现行」保留当前角色目录中的完整异能和终结，供逐项对照；各私有机制仍按原机制说明，例如独行、幻境、同频合击、救世魔女。
- 「本轮调整」为本轮编辑采用的方向，未写明的内容不附加此前候选增益；「建议」仍是未采用候选，数值可直接修改。
- 通用「环合」仍指属性组合反应；「援护技」仍指满足规则的出击。单纯追击、同频合击或持续伤害不擅自视为消耗过 3 点环合。
- 次数限制以各自正文为准，不为本轮调整擅自增加每回合上限。已有次数不因倒地／复活／换人刷新；直接施加效果不伪造支付环合的事件。
- 终结需求先保留现行基础值；白热化仍另行处理。黑羽为魂属性但基础需求特别为 5；浔使用时计。
- 可以直接修改各节的异能／终结正文。「本轮调整」已勾选；仍含占位的角色标为待补，不据此实施不完整效果。其余未勾选建议不视为已采用。
- 所有强化标题统一为 `【创生】强化`、`【浊燃】强化` 等格式，将「强化」置于【】外。

### 1. 娜娜莉（灵；终结 5 点能量）

- 调整方向：参与创生获得成长，创生／覆纹追击。
- 现行异能：首个己方回合开始时获得 1 张「家族壮大」。娜娜莉击退对方异能者时，若仍存活且在战斗区，再获得 1 张「家族壮大」。至多获得 3 次。

首个己方回合开始时，或娜娜莉参与触发【创生】时，获得 1 张「家族壮大」。至多获得 3 次。

**本轮调整：终结**
