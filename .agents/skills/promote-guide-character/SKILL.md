# Wiki角色转正

让角色进入完整正式模板，并使目录、网页、JSON／Markdown、CLI、攻略助手和可用工具保持一致。角色身份、数据是否完整、资料开放时间、排轴／空幕账号权限是不同状态，分别处理。

先完整读取根`AGENTS.md`及`app/modules/guide/README.md`。涉及图片，读取`app/static/AGENTS.md`、`docs/character-image-assets.md`；修改其他模块时再按根导航读取该模块文档和技能。遵循仓库不新增来源台账的约定，仍需实际核实每个字段。

## 确定本轮范围

- 按用户最新选择确定哪些角色转正；仅同步上游、资料到达开放时间或发现真实编号，不自动改变预告状态。已明确回退的角色保持预告，除非用户重新要求转正。
- 核实真实角色ID、名称、默认造型、属性、稀有度和弧盘适配。不能用NPC编号、相似角色或列表顺序补值。
- 比较当前NTEData实际配置与本地资料，先识别改动再导入。请求和网站启动不得联网；下载与校对仅在显式离线刷新中执行。
- 检查角色主表、技能说明、伤害引用和觉醒资源是否为空或借用了其他角色。不能用通用占位正文、他人图标或无依据面板把转正流程“补齐”。缺项明确列出并保留空值；核心资料不成立时保留预告，除非用户明确要求正式模板中留空。用户确认的数值按确定值处理，不再标成估算。

## 核实完整资料与专属弧盘

角色资料覆盖：基础面板与等级／突破成长、暴击／暴伤、角色标签、普通攻击／变轨／终结／援护、天赋／特性／都市技能、基础冷却、逐级参数与真实命中、觉醒／共鸣、机制词条、空幕及驱动特化、经验与突破／技能费用、好感度／赠礼。

独立核对专属弧盘，不能把“同类型弧盘可选”当成专属弧盘已收录：

1. 读取养成推荐表的角色绑定，确认首个推荐弧盘ID；再核对弧盘物品配置和实际专属效果绑定。推荐关系与专属关系分别保存，不由名字推断适配类型或专属效果。
2. 检查弧盘目录、中文名称、稀有度／类型、1–80级属性、完整混频档位、效果正文和参数、突破材料及经验包、本地WebP图片。目录图按`ItemIcon`核实并与现有图标对齐；`ForkCard`可能是带黑底的宣传卡面，不直接代作透明物品图标。
3. 补齐`data/arc_cultivation.json`的弧盘配置与角色推荐；验证角色页弧盘跳转、养成预选／合并费用、一图流候选与默认推荐都指向真实条目。
4. 上游已经有而远端静态索引尚未收录的弧盘，做独立本地导入并纳入常规刷新保留机制；不要为补一个条目覆盖整份目录或丢弃其他独立导入角色／弧盘。

好感度主表缺失时，独立检查礼物绑定；保留可用赠礼，不伪造等级奖励和属性加成。确认通用满好感需求时可单独计算总花费，未知售价保持空值。

## 技能判定与时长（所有角色）

1. 按技能蓝图、实际绑定的动画段、动画通知和伤害效果逐动作核对，覆盖普攻各段及末段、分支、派生招式、形态、变轨、终结、援护、下落、闪反等实际存在的动作。使用 `scripts/sync_guide_combat_details.py` 离线生成 `app/modules/guide/data/skill_combat_details.json`，核对 `skill_combat_overrides.json` 中的人工表格和表注。缺少核心绑定时保留已有快照，缺失字段留空；不用其他段或其他角色的值补齐。
2. 「动作占时」与「允许跳跃（秒）」分列。普通占时从该动画段起点计：普攻中间段优先取已确认的同链下一段衔接点；其他动作按已确认的衔接、通用技能开放或结束能力通知推算。黑羽等角色已有明确指定的时长按角色口径保留。不取跳跃取消与技能取消的最小值，不因补录允许跳跃或刷新数据改写既有普通占时。
3. 从 `BP_CanBreakSkill` 的 `BreakSkill_Jump` 读取该动作段最早允许跳跃的时点，单独展示相对动画段起点的原始时间；未配置则留空。`BreakSkill_AnySkill` 是通用技能取消；`BP_JumpSection` 是招式连段窗口，不是角色跳跃，也不表示能切人。连段窗口等动画事件保留原始相对时间；特殊连段注明目标招式与段数，配置明确的输入或条件一起写入表注。例如黑羽 Q 的窗口指向变身普攻第 3 段，不填作「允许跳跃」。
4. 计算实际占时时，只计入对应节点前可核实的直接命中和固定伤害体顿帧，不计入节点后的顿帧，也不把命中后有条件才生成的伤害体当成固定顿帧。闪反从闪避起手计，前闪、后闪分别核对；排轴取较慢的一种。时停、切人等既有有效 0 秒动作和缺少完整依据的条目保留原配置。
5. 对已经接入排轴且能明确对应的动作，按排轴规则把跳跃时点换算为实际占用（只计该时点前可核实的顿帧，再向上取到 0.1 秒）。仅在换算结果严格短于既有普通占时、且无明确角色例外时，复用步骤可选「脱手」，不改 `duration_seconds`／`duration_ticks`。给跳跃脱手标记 `detach_via_jump`：仅缩短步骤占用，保留完整伤害、资源和前台锁定，不作为合轴切人点。保留明确指定的已有脱手配置与固定占用例外。修改排轴前完整读取模块 README 与 `docs/shaft-character-actions.md`；没有排轴动作映射时不凭 Wiki 上线创建排轴机制或扩大账号权限。

## 正式目录与模板

以现有完整角色和`tests/test_guide_elyms_complete.py`为模板契约，按实际数据结构维护：

| 责任 | 当前入口 |
| --- | --- |
| 正式资料与养成上限 | `app/modules/guide/data/catalog.json`、`ntedata_characters.json` |
| 属性／适配／标签 | `data/character_metadata.json` |
| 本地头像与两种立绘 | `app/static/images/characters/index.json` |
| 技能／觉醒图标与富文本 | `data/skill_icons.json`、`passive_icons.json`、`character_rich_text.json` |
| 好感、弧盘与工具绑定 | `data/affinity.json`、`arc_cultivation.json`、`kongmu_links.json`、`overlap_links.json` |
| 预告与开放时间 | `data/character_previews.json`、`character_preview_details.json`、`character_releases.json` |

复用`guide/detail.html`正式模板：开头身份／属性／星级／适配／标签／立绘、属性滑块与材料概览、角色工具、相关攻略、章节目录、技能、觉醒、共鸣、机制词条、空幕、好感度与数值约定。确实缺失的数据采用明确空缺状态；不要保留预告模板、预告标记，或只换模板类名而漏掉模块。

移除对应预告记录，避免目录重复；正式ID迁移后同步开放时间身份映射和需要保留的旧链接。默认刷新必须保留本地独立导入条目，重复导入不重复增加记录，也不覆盖其他角色。

## 图片与头像：调用裁剪技能

在本流程中新增或更新角色头像时，必须读取并执行同仓库的[crop-character-avatars](../crop-character-avatars/SKILL.md)，不要复制或另造裁剪规范。

该子流程包括核实默认造型、从立绘主动裁剪、与早雾／薄荷等现有头像比较视平线和人脸大小、256×256 RGBA无损WebP、共享资源绑定／旧地址兼容及缓存处理。每名角色独立确定取景框，不套用其他角色坐标；具体坐标仅属于该角色的复现与像素验证。立绘保持对应展示画布和原生高清构图。

## 工具与访问边界

- 养成：核实实际等级上限、突破、经验书、技能费用，以及专属／同类型弧盘预选与总花费；不能只验证页面返回200。
- 排轴与配装：检查当前角色筛选、实际轴读取和无结果／无权限状态。Wiki转正不创建排轴机制，不把测试角色公开；保持现有测试、受邀、正式账号的边界。
- 空幕：核对真实角色ID、推荐卡带和可计算方案；未接入则明确不可用，不跳到别的角色代算。
- 一图流：核实图片、弧盘／卡带候选和默认绑定，保持登录鉴权与账号隔离草稿。
- 相关攻略：正式ID可挂载，不能因身份迁移丢失已有文章或暴露草稿。

## 上线时间与机器读取

沿用`character_release.py`，按带UTC+8偏移的完整日期比较服务器时刻。正式模板不代表技能已开放；上线前从技能起的后续资料在网页、JSON／Markdown、窄字段读取、检索／目录文本和助手工具同时隐藏。不能只在浏览器里折叠、把隐藏正文塞进HTML或让助手从记忆／外部搜索补出。

养成在开放前只计算允许的角色／弧盘范围，不泄露技能名称与费用；一图流使用已公开身份／图片与用户自填内容。自动刷新以服务器状态为准，不用本机日期解锁。时间到点不自动生成缺失资料，也不自动把预告角色转正。

## 验证与交付

为本次角色维护可运行的UT，断言模板全部模块的实际内容或明确空缺状态，且逐项验证：

- 正式目录唯一、无预告标记，属性／标签／图片／材料／技能／觉醒／共鸣／词条／空幕／好感与机器读取一致。
- 「判定与时长」在网页与鉴权 JSON／Markdown／CLI 一致；核对普通占时未变、允许跳跃与连段不混写。涉及排轴时，验证默认步骤占用不变、仅合格动作提供可选脱手，以及脱手保留完整结算。
- 专属弧盘确实收录，图片可解码，角色跳转和推荐正确，等级属性／混频效果／材料及合并养成费用正确；刷新与重复导入不丢条目。
- 工具能实际使用；未接入／无权限有正确结果；头像尺寸、透明通道与确定性裁剪逐像素一致。
- 上线前、恰好到点、上线后及UTC等价时刻；缓存预热后仍按每次请求切换；公开格式、检索与助手均无泄露，排轴权限不变。

完整资料回归使用明确的开放后测试时钟；时间边界测试独立控制时钟，不依赖跑测试当天。运行受影响用例及完整攻略回归；按实际改动追加空幕、排轴、图片等回归。用仓库浏览器验收流程检查桌面／手机的真实目录、详情和工具，检查破图、控制台错误和溢出。

更新模块README与必要资源说明；交付列明完成项及实际缺项。按根规则仅暂存本任务文件并自动提交；推送／发布沿用所属模块与用户授权，不因创建skill而发布网站。
