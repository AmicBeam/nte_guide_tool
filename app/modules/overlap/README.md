# 合轴收益表

第四个独立工具模块，入口 `/overlap`。首版支持安魂曲远程、残虹现实/幻境、黑羽魔女形态与明音凛；主要统计普攻、重击，黑羽额外统计魔E衔接。

网页读取已生成的静态 JSON，只做角色选择、搜索、排序与展开。路线使用紧凑动作气泡，前台起手实线、后台释放虚线，切走/回场及预输入/脱手/闪分别标记；闪以 `魔a3闪` 等原动作名加闪表示，明细记录被替代动作。前后台标记由离线生成的前排区间投影，网页不计算规则。没有计算 API、方案写库、训练依赖；网页请求和网站启动均不运行生成脚本。

## 目录与生成

- `data/rules.json`：角色范围、动作白名单、衔接图、预输入例外与来源。
- `generator.py`：离线枚举、时间安排与裸收益加总。
- `static/data/tables.json`：随网站发布的静态结果，附输入 SHA-256。
- `templates/overlap/index.html`、`static/js/overlap.js`、`static/css/overlap.css`：独立展示页面。
- `scripts/generate_overlap_tables.py`：生成入口，不导入 Flask 应用、不初始化数据库。

只读取排轴的 `actions.json` / `characters.json` 数据文件，不依赖排轴领域服务；不修改排轴动作或权限。更新动作数值或合轴配置后显式运行：

```bash
python3 scripts/generate_overlap_tables.py
python3 -m unittest tests.test_overlap_tables tests.test_module_routes -v
node --check app/modules/overlap/static/js/overlap.js
```

`--rules PATH --output PATH` 可生成临时版本。输入缺时长时输出 `null`，不把占位0秒算作真实免费动作；不认识的角色、动作、没有来源的衔接或超出枚举边界均报错。生成文件必须一起提交，不能在请求时自动重算。

## 现行合轴口径

由用户2026-10-12确认：普攻默认顺序衔接；前一个动作开始0.2秒后输入下一动作即可切人，当前动作与已输入的下一动作在后台完整释放。操作名使用 `a3预a4`，起手段在完整路线中展示；输入时刻与实际释放时刻分开记录。明音不支持 `a3预a4` 合轴，只保留完整顺接。

安魂曲仅远程、不支持闪避保留连段；其他三人的所列形态均支持。只尝试把超过0.7秒的中间普攻替换为0.7秒的闪，首末段不替换；跳过动作的倍率、环合、回能和个人资源全为0。不用排轴通用0.5秒闪覆盖这个模块的用户指定0.7秒规则。魔a5之后要接魔E的路线必须实际打出魔a5，不能以闪跳过激活前置。

衔接动作合轴：在预输入尾段结束时切回来继续下一段。窗口1为首次切走到尾段释放结束；窗口不足1.2秒不生成。允许回场范围为 `[首次切走+1.2秒, 尾段结束]`，结果选尾段结束时回场，累计两段前台时间。窗口只描述可供其他角色使用的时间，不编造队友操作与收益，也不添加未知的连段宽限期。

黑羽魔a5接魔E时改用现有脱手版本0.6秒，伤害与资源完整保留；魔E后可接魔z2，魔z2自动接魔a3。只有这些显式回接路线允许按 `max_uses` 再走一次魔a3–魔a5，魔E仍最多一次；不是无限连段或技能CD搜索。

衔接配置可写 `input_delay_seconds`（从前动作开始到输入的延迟）、`switch_delay_seconds`（输入后额外等待）、`can_preinput=false`（只顺接）、`detach_previous=true`（前动作必须脱手）、`automatic=true`（自动衔接，无再次手动输入）、`requires_previous` / `requires_prefix`（上下文约束）。这些属性分别记录输入、合轴与释放时刻，避免把延后合轴误算为丢伤害。

## 来源与收益边界

三份腾讯资料于2026-10-12读取：

- [明音凛](https://docs.qq.com/aio/DVWd1dEhxd1ZEU25Y)：闪避保留连段及预输入描述。
- [黑羽](https://docs.qq.com/aio/DVVRZempSSmZ4THVj)：普通z插a1/a2/a3且保持段数；魔a2接魔z1、魔z1接魔z2、魔z2自动接魔a3。
- [残虹](https://docs.qq.com/aio/DVXF0ZkVKSEV3Y2t4)：现实与幻境a1/a2可插重击。用户本轮进一步确认两种插入点均接本形态末段：现实a5、幻境幻a4。

只摘取所需衔接语义，不保存原文全文、鉴权数据或其中的攻略评价。数值继续读取仓库当前维护值；腾讯文档旧数值不回退仓库已确认的新口径。例如明音耗时仍为2026-10-11的0.5/0.5/1.1/0.7秒。残虹/黑羽等经验耗时是试算分母，不宣称为实测帧数。

倍率按攻击/生命/防御/固定基准分别加总；动作回能、固定返还、耗能与净能量分别记录；环合本体与释放奖励分列。`/秒`分母为累计前排占轴，不是完整释放时间。不模拟Buff、配装、资源上限/溢出、队友回能分享、形态激活、恶意追加及DOT后续伤害，不等价于真实DPS。幻境和魔形态路线以该形态已建立为前提；尾段离场与再次回场的连段保留采用用户本次指定的参考表口径，不改变排轴引擎。

验收包含生成结果与输入一致、预输入时间、明音例外、闪收益归零、1.2秒窗口边界、分段占轴、魔E脱手/自动回接，以及真实页面筛选、明细和手机横向滚动。
