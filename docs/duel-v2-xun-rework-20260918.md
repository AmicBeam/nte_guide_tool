## 实现边界

- 荒时贡献按实体在两次浔终结之间去重；消耗后重新累计。大家庭未额外声明免费，沿用 1 费；随机古董为零费。
- 召唤物只占前排，不加入备战区四人编队，不参与普通出击、终结或能量分享；倒地／离场立即消失。占位美术使用通用召唤物标志。
- 私有快照、随机状态与可检视牌库从公开投影／回放隔离；请求版本与事件序号在回溯后仍递增，移除账本不回溯。
- 浔仍仅测试账号可用；旧浔对局应重新开局。原有卡牌 ID 复用于新效果，不保证旧浔快照仍按旧规则运行。
